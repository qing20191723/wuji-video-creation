01－01｜钟表修理铺｜傍晚｜内

柜台后的老周合上木工具箱，伸手关掉台灯。窗外的天色淡了。

门外传来成年顾客的声音：“师傅，还能修吗？”

老周望向门口，手仍搁在工具箱上。他低头看了一眼已经收好的工具箱，又把台灯打开，掀起箱盖。

老周：“能。进来吧。”

他拿起螺丝刀，往门口望去。
