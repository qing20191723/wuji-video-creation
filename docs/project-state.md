- 当前推荐 SOP：`品牌AI剪辑协作SOP_v2.pdf`（文档版本 V1.1）。
- 历史对照：`品牌AI剪辑协作SOP_v1.pdf`（文档版本 V1.0）。
- 核心方法：脚本锁、资产锁、画面锁；A/B 类修改分级；意见汇总；云端初版验收；无水印母版和有水印发布版双版本交付。
- 影视生产 Skill：`skills/seedance-film-production/`，项目状态 schema `1.5`，兼容读取 `1.1`–`1.4`。
- 交互基线：完整项目使用 G1–G7；剧本会诊、对白精修、平台节奏体检和后期声音设计使用单点专科模式。
- 边界基线：G1–G7 只锁定创作内容；外部视频协作确认表/Google Sheet 不进入 Skill schema，继续独立管理团队协作与交付状态。
- 模型基线：正常段使用 Seedance 2.5，成人段使用 Wan 3.0；两者单次均不超过 30 秒并原生音画一体，实际入口限制记录在各自 `model_profile`。
- 创作基线：人物、因果和可表演性优先；片段时长自适应且不超过模型入口上限；文戏和武戏均不设最低或固定镜头数。完整生产的正常段固定使用 4×4 十六宫格做视觉锁定，但 16 格是关键状态而不是 16 个视频镜头，不能反推切镜或时长。
- 成人内容基线：先完整理解原文并逐跨度路由，在可处理边界内不省略、不用含糊摘要代替成人剧情；成人段不制作十六宫格，只生成必要资产图与 Wan 3.0 自然语言视频提示词。仍必须锁定成年、来源授权、持续同意、内容等级与镜头边界；禁止校园/幼态、非自愿、真实第三方性化和审核规避。
