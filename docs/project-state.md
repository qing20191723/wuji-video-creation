## 当前事实源

- 当前推荐 SOP：`品牌AI剪辑协作SOP_v2.pdf`（文档版本 V1.1）。
- 历史对照：`品牌AI剪辑协作SOP_v1.pdf`（文档版本 V1.0）。
- 核心方法：脚本锁、资产锁、画面锁；A/B 类修改分级；意见汇总；云端初版验收；无水印母版和有水印发布版双版本交付。
- 影视生产 Skill：`skills/seedance-film-production/`，Skill 包版本 `2.0.0`；项目状态 schema `1.9`，兼容读取 `1.1`–`1.8` 并提示升级。
- 交互基线：完整项目使用 G1–G7；剧本会诊、对白精修、表演设计、平台节奏体检和后期声音设计使用单点专科模式。
- 边界基线：G1–G7 只锁定创作内容；外部视频协作确认表/Google Sheet 不进入 Skill schema，继续独立管理团队协作与交付状态。
- 模型基线：正常段使用 Seedance 2.5，成人段使用 Wan 3.0；两者单次均不超过 30 秒并原生音画一体，实际入口限制记录在各自 `model_profile`。Wan 3.0 官方提示词上限为 20,000 字符；Seedance 2.5 官方未公布字符上限，Schema 分开记录官方状态、当前入口有效硬限制与制作软预算。
- 创作基线：每个视频单元是一段讲清当前故事意义的“叙事段落”；意义成立且继续拍摄只会重复时结束。下一段从人物、动作、结果、物体、空间或声音重新入场，继承故事世界与因果，但可重新选择摄影机位置、景别、焦点和运动。片长与镜头数由实际可拍意义决定，不用模型上限、镜头配额或十六格反推剧情。
- 生成基线：每段 Seedance/Wan 视频都依赖已批准 Canon 和资产，可独立并行生成，不以延长上一条生成视频为默认工作流；相邻单元使用 `straight-cut`、`shared-boundary` 或有新增组合意义的 `montage-cut`，只有精确动作确需无缝边界时才绑定共享关键帧。
- 成人内容基线：先完整理解原文并逐跨度路由，在可处理边界内不省略、不用含糊摘要代替成人剧情；成人段不制作十六宫格，只生成必要资产图与 Wan 3.0 自然语言视频提示词。在已批准范围内直述裸体/覆盖、姿态、承重、行为类别、节奏、持续回应、同步声音和末状态；当前执行环境不能展开的细部保留中性类别和原文跨度，不静默删除。仍必须锁定成年、来源授权、持续同意、内容等级与镜头边界；禁止校园/幼态、非自愿、真实第三方性化和审核规避。
- 表演/摄影基线：表演使用“事件触发—六轨选材—强度—残留”，复合情绪只保留一个泄露信号；每次摄影变化记录触发事件、摄影反应及其揭示的新意义，全局光影由有来源主光、反差、综合色温和曝光重点约束。
- 段落移交基线：相邻片段只移交上一段已完成意义、未完成冲动、下一段再入场锚点和必须继承的故事状态，不把它解释为剪点表，也不默认继承上一台摄影机。
