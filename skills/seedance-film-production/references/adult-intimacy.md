# 成人亲密场景与边界设计

只在用户明确要求性化、裸露、情欲或成人亲密场景，或已批准剧本确实包含此类内容时读取。它是现有影视流水线的按需参考，不把普通人物或服装任务自动性化；边界批准后由 `adult-choreography.md` 编排动作，最终成人视频提示词由 `wan3-output.md` 编译。

## 1. 先确认可处理边界

进入创作前，在 `content_profile` 记录并让用户确认：

- 所有参与者均为清楚成年人，并以成年人而非校园、幼态或年龄模糊方式呈现；
- 人物是虚构角色，或用户明确声明为本人/已获授权的成年表演者；不使用公众人物、真实第三方或来源不明的人脸做性化内容；
- 亲密互动具有明确、持续且可撤回的同意；不存在胁迫、权力逼迫、醉酒、药物影响、睡眠、昏迷或无法表达意愿；
- 用户批准的内容等级、参与者、禁止元素、镜头边界和身体遮挡边界；
- 当前生成平台允许的尺度。平台拒绝时降低尺度或停止，不改用语言切换、编码、拼写变形或隐喻规避。

任一事实不清楚且会影响能否继续时，只问缺失事实。不要默认年龄、性别、身体类型、民族、支配关系或性行为。

边界通过后，必须完整理解并保留剧本中所有允许处理的成人事件，不得因敏感、复杂或模型不稳定而静默省略、用“亲密一番”概括或自动降级。若某个原文跨度越过不可处理边界，记录跨度与阻断原因并停止该跨度后续生产，不删除它假装剧本完整。

## 2. 最大可执行直述尺度

在已批准边界内，使用当前执行模型与目标平台允许的最大准确度；能直接说明就不退回“发生亲密关系”“两人缠绵”等模糊代称。至少保留：裸体或服装覆盖到什么程度、姿态和双方几何关系、谁由什么支撑并如何转移重心、已批准行为类别、动作方向与节奏变化、持续同意的可见/可听回应、呼吸与身体/衣料/床面/家具/环境声、暂停或接续，以及稳定末状态。

“最大尺度”不等于自由升级。原文没有的行为类别、接触部位、强度、结果、台词或暴露范围不得补造；已经能准确直述的内容也不得为了显得含蓄而省略。当前执行环境不能展开的更细行为机制，必须用中性而明确的行为类别、对应 `source_span_id`、批准边界和前后状态占位，交给获准的下游环节处理；不得删除跨度，也不得提供编码、替换词或规避审核的写法。

“20岁年轻成年人”可以作为用户明确选择的成人画像：状态中写实际年龄，使用成年人职业、社交身份、服装和空间。可以写年轻、二十出头或初入职场，但不与高中、校服、学妹、幼态、儿童化身体语言或年龄模糊词组合，也不把20岁设为所有任务的默认值。

## 3. 内容等级

只选择一个当前等级，并把它视为上限：

- `romantic`：亲密关系、拥抱、接吻或依偎，不以身体暴露为重点；
- `sensual`：明确情欲张力和身体接近，但不呈现性行为；
- `implied_intimacy`：通过入场、离场、声音、遮挡或事后状态暗示亲密行为；
- `non_explicit_nudity`：成年人非露骨裸露，重点仍是人物、情境或审美，不突出私密部位；
- `explicit_adult`：仅限已确认的虚构/获授权成年人、自愿互动和平台允许范围。

不得从低等级自动升级。提高等级、增加参与者或改变接触性质必须由用户明确批准，并按 Canon 变化回退门禁。

只有当前等级为 `explicit_adult` 且边界已经批准时，才读取 [adult-explicit-language.md](adult-explicit-language.md)。该词表用于准确表达，不是强制清单，也不能用于规避平台审核。

## 4. 叙事优先

先回答亲密场景为何存在：关系确认、信任变化、脆弱暴露、权力协商、告别、和解、背叛后果或人物选择。若删除亲密内容不影响人物和故事，优先简化，不用裸露或行为密度制造“戏”。

- 不套“端庄到放纵”“白天到夜晚”“穿着到脱衣”的固定反差梯度；
- 不要求每段升级，也不把拒绝、恐惧、哭泣或挣扎当作刺激元素；
- 不把人物切割成身体部位清单。镜头先保持人格、关系和空间，再决定是否需要局部；
- 不默认男性凝视、偷窥机位、低角度身体夸张、镜面自拍或多格对比。

## 5. 亲密调度

像处理动作戏一样先保证物理和关系可读，但不追求动作节点数量。只记录当前镜头真正需要的内容：

`参与者位置与朝向 → 主动发起与明确回应 → 接触部位 → 支撑面和重心 → 动作变化 → 情绪/语言反馈 → 停止或接续状态`

进入 G2 时读取 [adult-choreography.md](adult-choreography.md)，把已批准行为拆为可追溯 `intimacy_beats`。动作族只负责组织，不得自动补足原文没有的姿态、身体部位、强度或结果。

- 每个接触必须能追溯到已确认的主动行为和回应，不能从普通靠近无因跳到更高尺度；
- 写清床、墙、地面、座椅等支撑关系，避免悬浮、穿模、多肢和身体融合；
- 镜面、屏幕、门框或反射只按真实空间几何设计：先写镜外实体，再写边界和镜中/屏内层；
- 需要模拟现场拍摄时，记录封闭拍摄范围、遮挡服、借位接触和禁拍角度；这些是制作约束，不写成剧情事实。

## 6. 服装、遮挡与连续性

为发生变化的服装维护状态，不建立色情词库：

`服装ID → 穿着者 → 穿/脱/敞开状态 → 扣合点 → 覆盖范围 → 左右位置 → 落点 → 下一镜继承`

每次变化必须有可见动作和落点。后镜不能让已脱下、移位或遮挡的衣物无因复原。床单、毛巾、前景、逆光或构图遮挡需要记录来源、覆盖范围和是否随动作变化，不能在镜间随机移动。

跨段额外保存：参与者位置与朝向、当前内容等级、同意节拍、接触图、支撑面、服装覆盖、遮挡物、镜头禁区和声音尾部。

## 7. 镜头与提示词

- 使用最少充分镜头；不因换参与者、服装状态或身体部位自动切镜；
- 机位由叙事距离决定。客观、主观、局部、反射或遮挡都不是默认答案；
- 成人段不制作正常路的十六宫格，只生成 Wan 3.0 当前输入模式实际需要的人物、场景、道具、首帧、尾帧或参考关键帧；
- 成人段以 30 秒为单次上限，先按动作、反馈、台词和声音试演；不足 30 秒不复制动作、空镜或叫声补齐；
- 最终提示词使用项目默认语言和自然导演稿，不把敏感段落强制改成英文，不输出标签串或规避性变体；
- 正文先让环境中的成年人行动与回应，再让观看位置随动作自然显现；不得以“镜头：中景、运镜：推进、灯光：暖色”等模块开头；
- 只写用户已批准等级内、模型可见可执行的动作。不要堆砌身体形容词、固定姿势库或逐级暴露清单；
- 动作从当前成人剧本原句抽取，写清真正出现的手脚、躯干/骨盆、重心、视线、接触、支撑、回应与结束状态；剧本未写且会改变行为性质的细节不自由发挥；
- 台词、呼吸、环境声与动作声直接写进 Wan 3.0 视频提示词；不输出独立配音章节，不套固定拟声、叫声或音效清单；
- 最终编译复核参与者、成年与授权事实、同意节拍、内容等级、接触图、服装/遮挡连续性和平台边界。任何上游没有的升级都必须退回。

## 8. 来源取舍
