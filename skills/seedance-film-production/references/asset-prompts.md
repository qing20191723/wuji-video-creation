# 可直接生成的资产提示词

## 核心要求

资产台账可以使用字段，但交给用户和图像模型的资产提示词必须是自然、完整、连续的中文描述。每项资产输出：

1. 资产ID与用途说明（放在提示词外）；
2. 一段可直接复制的正向提示词；
3. 一行只包含必要风险的负面约束；
4. 使用哪张已确认资产作为参考。

不得把“身份、服装、摄影、背景、禁止项”标签清单冒充成提示词。

静态资产与故事板提示词按以下次序展开：`主体与叙事目标 → 主导点 → 引导线的起点与落点 → 前中后景与留白 → 视角/景别/裁切 → 可见来源光线 → 禁止项`。不要只写“点线面构图、电影感”；必须写出对象在画面何处、视线如何移动、哪些区域承担空间层和文字留白。

## 人物四项定妆资产

人物定妆资产固定生成在同一张横向四栏参考图中，不能拆成四张自由构图的独立图片。四栏从左到右依次是：正面半身面部近景、全身正面、全身90度标准侧面、全身背面。第一栏可比后三栏宽，以确保脸部细节清楚；后三栏人物等高、脚底处于同一基线。

自然语言模板：

```text
创作一张{角色名 / CHAR-A01}的电影人物定妆四视图基准图，横向画布划分为连续四栏，画面中四栏始终是同一名角色，不出现第二个人。角色是{身份、年龄层、时代背景}，拥有{稳定的脸部骨相、五官、肤色、体型、发型和识别特征}，穿着{从内到外描述服装结构、版型、主辅色、面料、鞋和配饰}，造型体现{职业、阶层、经历与性格}。四栏从左到右固定排列：第一栏为正面半身面部近景，可适当加宽，人物自然站立，肩线平稳，头部不偏转、不俯仰，面部、鼻尖和双眼正对镜头，视线平视镜头，清楚呈现正面脸部骨相、五官、妆面、发际线、发型、领口、肩部与上半身服装；第二栏为全身正面，人物自然中性站立，头部、面部和双眼正对镜头，双脚自然平行落地，双臂自然下垂并略离躯干，完整露出服装正面、双手、裤裙、鞋和配饰；第三栏为全身90度标准侧面，头部与身体保持同一侧向，双眼自然看向身体朝向，不回头看镜头，准确呈现鼻梁、下颌、头身厚度、服装侧面轮廓和鞋；第四栏为全身背面，头部与身体都背对镜头，完整呈现后脑发型、服装背面结构、后侧配饰和鞋跟。人物不插兜、不叉腰、不交叉手臂、不做动态姿势或宣传造型。四栏必须保持同一张脸、同一年龄、同一体型、同一妆发、同一套服装和同一材质；后三个全身栏位保持相同人物高度、相同脚底基线、平视中长焦、自然透视、均匀柔光与统一浅灰中性背景。整体遵循{项目画风}，这张图作为后续表情、状态变化、故事板和视频镜头的唯一人物身份母版。
```

负面约束示例：

```text
不要额外人物、不要文字水印、不要拆成四张风格不一致的独立图、不要改变四栏顺序、不要夸张海报光效、不要动态姿势、不要插兜叉腰或交叉手臂、不要裁掉全身视图脚部、不要遮挡服装结构、不要四种不同造型、不要换脸、不要年龄体型漂移、不要让正面半身或全身正面低头侧脸斜视、不要用3/4角度冒充90度标准侧面。
```

### 表情与状态板

```text
以已确认的人物四项定妆资产为唯一身份参考，生成同一角色的{所需的5种基础表情或服装状态}，保持脸部骨相、年龄、肤色、发型、妆面、服装结构和配饰完全一致。表情只改变眉眼、嘴部、呼吸和轻微头部姿态；服装状态只改变已指定的湿污、灰尘或战损位置。采用统一焦段、统一眼平高度、统一柔光和中性背景，不重新设计人物。
```

## 场景资产

场景先做无人干净母版，再做行动轴方向补充图。

```text
创作{SCN-01场景名称}的电影级无人场景母版。这里是{时代、地点、用途与叙事气氛}，前景包含{锚点}，中景是主要人物行动区域{具体空间与可交互物}，后景能清楚看到{出口、纵深与固定地标}。建筑、家具、地面、门窗和装饰使用{材质与磨损状态}，主光从画面{方向}进入，时间与天气为{条件}，所有阴影方向一致。使用能清楚交代空间地理的宽幅建立镜头，透视自然，保留A→B→C行动路线和可破坏区域，不出现人物、文字或随机新增物件。这张图作为后续所有镜头的场景空间与光线母版，必须能与反向轴视图保持同一布局。
```

## 成人段资产

成人段仍遵守“只生成会复用、决定身份或影响连续性的资产”。人物四项定妆母版、场景和道具沿用上述自然语言规则；只有已批准成人剧本确实出现裸露、覆盖变化或明确接触时，才增加对应服装/覆盖状态资产和 Wan 3.0 所需首帧、尾帧或参考关键帧。

- 不默认生成“着装版+裸身版”双套人物资产，也不套固定体型、身体比例、毛发、配饰或行为模板；
- 需要裸露状态时，只写当前 `content_profile` 已批准且连续性必需的可见身体特征、覆盖范围与识别点；
- 成人关键帧是静态结果：写清人物位置、朝向、接触、支撑、重心、服装/遮挡、表情和镜头视角，不写“手从哪里移动到哪里”的过程；动作过程留给 Wan 3.0 视频提示词；
- 每条关键帧提示词开头直接说明真实参考图及人物/场景职责，不让用户回查编号表；未生成的参考图不得伪装成“图1”；
- 成人段资产图必须实际看图，检查身份、成年呈现、身体结构、接触、支撑、遮挡和边界后才批准。

### 跨模型中性边界关键帧

正常/成人路切换时，优先生成一张双方入口都可合法使用的中性边界关键帧。它停在最后一个非明确行为状态，只锁定人物位置、朝向、视线、身体重心、服装覆盖、空间地标、镜头观察位置、主光方向、综合色温和声音发生环境；不得包含成人路的第一个明确行为，也不得为了“过渡感”新增接触。

提示词必须直接说明它服务的 `transition_id` 和两端片段，继承两名角色与场景的已确认资产，用自然语言描述稳定静态结果。生成后同时按正常路边界和成人路边界验收；任一入口不允许使用时改为 `state_only` 移交，不用规避性构图伪装合法资产。

## 道具与武器资产

```text
创作{PROP-01/WEAPON-A01名称}的电影道具定型照，画面只出现这一件物品。它的实际尺寸约为{尺寸与人物比例}，整体轮廓是{形状}，由{材料}制成，具有{颜色、表面纹理、磨损、结构、开合或机关}，正反面和左右结构必须符合真实制造逻辑。以干净的3/4主视角展示完整造型，并在同一视觉体系下补充正面、侧面和关键结构细节，使用中性背景、柔和产品光和自然透视，清楚表现握持区、开口、刃口、连接件或内容物。不得增加文字、Logo、装饰性特效或与剧情无关的新机关；后续所有镜头必须沿用相同尺寸、材质和结构。
```

## 关键VFX资产

```text
为{VFX-01名称}设计一套电影级特效状态参考。特效明确从{人物/武器/装置/地面/空间位置}产生，核心形状为{轮廓与层级}，中心颜色是{核心色}，边缘过渡为{边缘色与透明度}，周围伴随{粒子、烟、火花、碎屑或空气扰动}。在同一套视觉语言中依次呈现蓄积、释放、传播、命中和余波五个状态，能看清运动方向、速度变化以及对地面、空气、水、布料和目标材质的反馈。使用深色或中性背景突出轮廓，所有状态保持同一来源、颜色和形状逻辑，不出现人物、文字、Logo或无来源随机发光。
```

## 提示词验收

- 是否是一段可直接复制的自然语言，而非标签堆叠；
- 是否明确单一主体、用途、构图、摄影、光线、背景和风格；
- 是否说明身份或空间从哪个已确认母版继承；
- 是否把可变项和不可变项分开；
- 是否避免一次提示词要求生成多套互相冲突的设计；
- 是否在同一张横向四栏图中严格按顺序包含正面半身面部近景、全身正面、全身90度标准侧面和全身背面；
- 四项是否为同一人物、同一妆发和同一服装。
- 正面半身与全身正面的头部、面部和双眼是否正对镜头，人物是否自然中性站立；
- 跨模型边界帧是否停在非明确状态，并完整锁定覆盖、观察位置和光影，而未重复下一段动作；
