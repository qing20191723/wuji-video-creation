# 剧本会诊与对白精修

本文件只在 `specialist` 模式的剧本会诊或对白精修中读取。它提供证据化诊断，不模拟评委圆桌，也不因用户粘贴文本而自动改写。

## 共同边界

- 先明确目标范围：全剧、单集、单场、单点、指定角色或指定台词。
- 诊断结论必须引用原文、场次、大纲条目或明确剧情事实。
- 只读诊断不改变 Canon、revision 或成果批准。
- 用户要求应用修改时，先展示修改稿与影响范围；使用 apply_change 登记修改，按受影响场次和依赖重新确认；无关批准保留。
- 用户锁定的台词、OS、事件顺序和结局不得改写；发现它们造成问题时只能报告影响并请求选择。
- 不承诺“必爆、必过审、必能拍”，不虚构从业履历或外部评委。

## 剧本会诊

### 输入粒度

- 全剧/完整大纲：结构、人物弧线、主题、因果、整体节奏与生产风险。
- 单集：开场、单集目标、推进、集尾钩子及上下集接口。
- 单场：场景目标、阻碍、策略变化、可见行动、对白和出口状态。
- 单点：只回答用户指定问题，不扩写成全剧审计。

材料只足以支撑较小粒度时，降级到可证实范围并说明；不要用想象补全缺失剧情。

### 诊断合同

每条有效发现使用：

```text
问题：可验证的具体问题
证据：原文短句、场次或明确剧情事实
影响：它如何影响理解、情绪、因果、节奏或生成稳定性
优先级：高 / 中 / 低
修改方向：目标和约束，不擅自替用户决定主题或结局
```

高优先级只用于导致故事无法成立、关键动机断裂、因果矛盾、角色严重失真或生成不可执行的问题。相同根因合并，避免用大量近义意见制造“专业感”。

输出顺序：会诊范围与前提 → 值得保留且不能误伤的内容 → 问题清单 → 修改顺序 → 是否应用。优点也必须有证据，但不要以客套话冲淡风险。

## 对白精修

### 六个诊断维度

1. **语言指纹**：遮住角色名后，词汇、句长、句式、时代语域和禁用词能否区分说话人。
2. **潜台词**：字面、真实意图和人物关系是否完全重合；直说是否削弱戏剧性。
3. **冲突推进**：台词后是否至少改变信息、立场、关系、情绪温度或下一步行动。
4. **类型语感**：用词是否符合年代、阶层、职业和作品类型。
5. **信息效率**：是否向本来就知道信息的角色解释设定，能否由行动、反应或道具承担。
6. **朗读与时长**：长短句、停顿、呼吸和片段时长是否允许自然说完。

语言指纹建议保存在角色的 `voiceprint`：

```text
vocabulary：常用词与称呼
sentence_length：短 / 中 / 长及例外
syntax：陈述、反问、打断、留白等习惯
era_register：年代、地域、职业与文化层
forbidden_terms：该角色不应使用的词或表达
```

口头禅不是必填项；不要为了区分角色给每个人硬塞口癖。角色辨识来自完整语言行为。

### 修改合同

只处理有证据的问题。每处使用：

```text
位置与说话人：
原台词：
命中维度与证据：
建议台词：
为什么这样改：
是否触及锁定事实：是 / 否
自然语速风险：低 / 中 / 高
表演与反应镜头需求：
```

不要逐句机械跑完六维，也不为追求“金句”破坏人物。台词较长时先给病灶总览，再按高优先级分批精修；每批必须保持上下文连续。

### 自然语速交接

- 用自然试读估算对白时长；停顿、压抑、哭腔、方言或复杂动作需要额外时间。不要用固定字数倒推台词，也不要为填满时长补对白。
- 一句完整台词优先在一个镜头内说完；跨镜时明确 L-cut/J-cut，台词只出现一次。
- 台词放不下时优先删重复信息、改成动作或拆分片段，不通过整体加速解决。
- 输出给分镜阶段：需要的倾听反应、沉默、呼吸、动作补偿和不可切断位置。

## 专科状态记录

在 `specialist_tasks` 中记录 `type`、`target_ids`、`status`、`source_revision` 和 findings。每条 finding 至少有 `priority`、`evidence`、`impact` 与 `recommendation`。只读诊断用 `diagnostic_only: true`；应用前改为 `awaiting_confirmation`，批准后按剧本回退规则更新主项目。
