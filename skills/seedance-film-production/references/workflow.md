# 完整工作流与门禁

本文件只规定阶段输入、交付、确认和回退；创作判断读取对应阶段参考。

## 输入与模式

盘点输入类型、已锁定事实、禁止改变项、允许补足项、素材职责、平台、画幅、风格、时长和内容边界。`full_production` 执行完整生产；`specialist` 只处理用户指定的剧本、对白、表演、节奏或声音问题。

专科只读诊断写入 `specialist_tasks`，不改 Canon。`performance_design` 列明目标片段/人物、来源证据和拟议表演弧线；批量修改先枚举全部受影响对象，应用后按表演 Canon 回退 G2–G7。

G1–G7 不记录负责人、审核人、Google Sheet、意见汇总、云端验收、水印交付或发布状态。

## S0–S10

- `S0 输入盘点`：建立来源锁定、任务模式、模型档案和内容边界。混合剧本逐跨度完成正常/成人路由。
- `S1 可生成剧本`：把文学内容改为可见行动、对白、OS、声音和物件因果，保留锁定事件与结局。
- `S2 项目圣经`：建立人物、关系、场景、资产、声音、空间与光影基线。
- `S3 叙事分段`：按 `narrative-direction.md` 判断每段意义、完成信号、前向冲动和再入场；再按真实表演估时。超过入口上限才在真实叙事边界拆分。
- `S4 文字分镜`：正常段写最少充分镜头；成人段写可追溯 `intimacy_beats`。每段保存表演、摄影、光影和状态。
- `S5 固定资产`：只抽取复用、身份或连续性需要的资产。
- `S6 资产生成`：按人物母版、覆盖状态、场景、道具/VFX、必要关键帧生成；正常段随后生成十六宫格。
- `S7 视觉验收`：实际查看像素，失败资产返修或停用。
- `S8 引用映射`：把通过验收的附件绑定稳定 ID 与唯一职责。
- `S9 双模型编译`：正常段逐叙事段落编译 Seedance，成人段编译 Wan；一次只加载当前模型规则。
- `S10 状态移交`：记录上一段完成意义、前向冲动、下一段再入场锚点和需继承的世界状态。

## G1–G7 交付

### G1 剧本

交付来源锁定、实质问题、跨度路由、完整可生成剧本、改编说明和待确认假设。此时不输出镜号、时间码、资产或视频提示词。剧本已定稿时可记 `not_required`，但仍需来源与路由台账。

确认问题：“这版剧本与正常/成人路由是否确认？确认后我按叙事段落和实际可拍时长设计分镜。”

### G2 分镜

交付项目圣经、叙事段落总表、正常分镜、成人动作/声画节拍、表演/摄影/光影、再入场和跨段状态。不要提前输出资产提示词或模型提示词。

确认问题：“这版叙事段落、分镜、再入场、成人节拍和连续状态是否确认？确认后我建立固定资产。”

### G3 资产提示词

交付资产 ID、复用范围、自然语言提示词和生成批次；确认后才调用图像生成。

### G4 人物定妆

每名主要角色生成一张横向四栏母版：正面半身、全身正面、全身 90 度侧面、全身背面。保持同一人物、妆发、服装、全身高度和脚底基线；实际看图后等待确认。

### G5 资产图

按小批次生成场景、道具/武器、VFX 和状态资产，每批实际验收。未批准角色不能进入其他资产和视频引用。

### G6 正常十六宫格

根据批准分镜决定每张画板覆盖哪些正常叙事段落。先交付图片提示词，再用批准资产生成并逐格验收。若扩展到相关正常段落后仍不足 16 个有因果价值的状态，且继续补格只会注水，则记录理由，把 G6 标为 `not_required`，以已批准关键帧或分镜资产进入 G7。成人段为 `not_required`。

### G7 最终编译

前序门禁均为 `approved/not_required` 后，逐段输出自然语言音画提示词。Seedance 绑定已验收正常故事板；Wan 按实际输入模式绑定成人资产。登记真实引用、字符数和 revision，不临场新增内容。

## 确认与状态卡

“确认、通过、按这版继续”只批准当前唯一等待门禁；“继续”只有在唯一门禁等待时等同批准。修改留在当前阶段，重新交付完整阶段成品后再等确认。用户明确放弃中途确认时仍逐阶段保存、验图和校验。

阶段末输出：

```text
【交互状态】
模式｜项目ID｜revision｜当前阶段
等待确认｜本次确认范围｜可选操作
修改后失效项｜下一步与所需材料
```

## Schema 1.8 契约

片段保留 1.7 的 `narrative_paragraph` 与 `reentry_plan`，新增 `composition_plan`；`camera_plan` 增加轴线、视线、屏幕方向和入/出镜动静状态，`viewpoint_turns` 使用统一摄影响应枚举。相邻片段各有唯一 `transition_ledger`，并以 `edit_bridge` 记录匹配依据、桥接方式、理由和主动断裂。精确动作确需连续时才附共享边界资产。成人段继续要求覆盖实际时长的 `intimacy_beats`，正常段不得携带。

`compiled_prompts` 每段只能有一条当前 revision 提示词。Wan 官方上限 20,000 字符；Seedance 官方上限保持未知，除非当前入口给出可核验数值。校验器兼容 1.1–1.7 并提示升级。

## 回退

- 剧情、人物关系、关键对白、结局、节奏或成人边界改变：提升 revision，回退 G1–G7。
- 叙事分段、再入场、表演、摄影、光影或跨段状态改变：保留 G1，回退 G2–G7。
- 资产改变：提升资产版本，回退相应资产阶段并重验引用。
- 只改成品措辞或模型内声音表达：回退 G7。
- 独立后期 Cue Sheet 不改变 Canon；修改固定对白仍按剧本变化处理。

最终交付依次包含项目锁定、剧本、叙事段落/分镜、资产与验收、正常十六宫格、双模型提示词和跨段状态。项目过长可以分批，但先交付全局圣经、完整段落表和资产总表。
