# 四个生产包与 G1–G7 门禁

本文件只规定输入、交付、确认和回退；创作判断读取对应阶段参考。取消与门禁重复的 S0–S10 编号，项目状态只显示 G1–G7 或 `specialist`。

## 输入与模式

盘点输入、锁定事实、禁止改变项、允许补足项、素材职责、平台、画幅、风格、时长和内容边界。`full_production` 依次交付四个生产包；`specialist` 只处理指定剧本、对白、表演、节奏或声音。只读诊断写入 `specialist_tasks`，不改 Canon；应用修改后按影响回退。G1–G7 不记录负责人、审核人、协作表、云端验收、水印交付或发布状态。

## 1. 剧本包

### G1 script_adaptation

交付来源锁定、实质问题、正常/成人跨度路由、按“集数-场次＋场景名＋时段＋内/外”书写的完整可生成剧本、改编说明和待确认假设。正文只含环境/场景、人物行动、人物对话及必要闪回标识，不输出镜号、景别、时间码、资产或模型提示词。已定稿剧本可把改编记为 `not_required`，但仍需来源与路由台账。

确认：“这版剧本与正常/成人路由是否确认？确认后我按每段要讲清的故事设计观看与分镜。”

## 2. 导演分镜包

### G2 shot_breakdown

交付视觉/声音圣经、叙事段落总表、主观看位置、必要补充视点、正常分镜、成人动作/声画节拍、表演/摄影/光影、再入场与相邻单元接合。每次换镜指出新增信息；先覆盖剧情，再决定镜头。不要提前输出资产或模型提示词。

确认：“这版故事覆盖、分镜、再入场、成人节拍和直拼接合是否确认？确认后我锁定资产。”

## 3. 资产包

### G3 asset_prompts

交付资产 ID、身份不变量/状态变量、唯一参考职责、复用范围、自然语言提示词和生成批次；确认后才生成。

### G4 character_look

每名主要角色生成并实际验收一张横向四栏母版：正面半身、全身正面、全身 90 度侧面、全身背面。同脸、体型、妆发、服装、全身高度和脚底基线。

### G5 asset_images

分批生成并查看场景、道具/武器、VFX、服装/覆盖状态、必要关键帧、动作/白模/摄影或声音参考。每项只承担已登记职责；未批准角色不能进入其他正式资产。

### G6 storyboard

正常路先交付 4×4 图片提示词，再用批准资产生成并逐格验收。十六格只覆盖批准镜头和动作相位，不反推镜头数。扩展相关正常段落后仍不足 16 个有因果价值状态时，记录理由并标 `not_required`，改用批准关键帧/分镜资产。成人路固定 `not_required`。

## 4. 模型编译包

### G7 final_compile

前序门禁为 `approved/not_required` 后，逐单元输出外部制作卡和一段自然音画导演稿。Seedance 绑定正常故事板/资产；Wan 使用获批成人资产与互斥输入模式。登记真实引用、字符数和 revision；最后给生成顺序、直接切接顺序和相邻 `assembly_contract`，不临场新增剧情。

## 确认与状态卡

“确认、通过、按这版继续”只批准当前唯一等待门禁；“继续”仅在唯一门禁等待时等同批准。修改留在当前阶段，完整重交后再等确认。用户明确放弃中途确认时仍逐阶段保存、验图和校验。

```text
【交互状态】
模式｜项目ID｜revision｜当前 G 阶段
等待确认｜本次确认范围｜修改后失效项
下一步｜需要的材料
```

## Schema 1.9

全局新增 `sound_bible`。片段保留 `narrative_paragraph / reentry_plan / performance_arc / lighting_state`；`composition_plan` 精简为五项；`camera_plan.continuity` 为具体对象或 `not-applicable`。相邻片段唯一 `transition_ledger` 使用 `assembly_contract`：`join_mode / visual_join / sound_join / combined_meaning`；蒙太奇关系可选，但新增意义必填。成人段要求覆盖实际时长的 `intimacy_beats`，正常段不得携带。

`compiled_prompts` 每段只能有一条当前 revision 正文。Wan 官方上限 20,000 字符；Seedance 官方上限保持未知，除非当前入口提供可核验值。兼容 1.1–1.8 并提示升级。

## 回退与完成

剧情、关系、关键对白、结局、节奏、路由或成人边界变化：提升 revision，回退 G1–G7。叙事分段、表演、摄影、光影或接合变化：保留 G1，回退 G2–G7。资产变化回退对应资产门禁并重验引用；只改成品措辞或模型内声音表达回退 G7。独立后期 Cue Sheet 不改变 Canon。

最终按剧本包、导演分镜包、资产包、模型编译包交付。项目过长可分批生成，但先锁全局圣经、完整段落表、资产总表和全片接合顺序。
