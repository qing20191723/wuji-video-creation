# 按事件检索的表演库

只读取当前冲突相关条目，通常一个主反应加一个泄露信号，转成动作、对白和声音。触发→回应→残留比标签更重要；强度来自事件代价，不来自固定秒点，中性定脸不限制强度。

| 检索 / 潜台词 | 触发后的可见选择 | 声音与身体 / 残留 |
| --- | --- | --- |
| 压怒 / 还不想撕破脸 | 越界后先把手中物件放稳，再指出行为 | 短句压低音量，答完不恢复亲近距离 |
| 爆发 / 终于说出口 | 忍耐失败，打断正在继续的行为 | 重心向前，说完呼吸未平，后句可能变轻 |
| 委屈 / 不想求你 | 被误解，解释失败后收回证据 | 嘴角绷紧、尾句轻，证据留在手里 |
| 悲伤 / 还得把事办完 | 确认损失后继续任务，一个熟练动作失败 | 迟半拍，手撑桌沿，整理好才抬头 |
| 隐痛 / 别看出来 | 旧事被提起，接住问题再转话题 | 声线平常，只露一次手指失准，仍避开物件 |
| 防备 / 你想要什么 | 对方接近时让出退路，观察其手部 | 重心留在可退出一侧，有证据才放松 |
| 恐惧 / 别惊动危险 | 停止动作、寻找真实出口 | 压低声音，抓住支撑物，威胁未消就仍警觉 |
| 惊讶 / 和预想不同 | 当前动作被新信息打断，查看证据 | 先停再问一句，判断改变后进入新反应 |
| 羞窘 / 被看穿 | 意图暴露后纠正次要细节 | 答得过快，绕开视线又回来，靠近仍克制 |
| 轻蔑 / 不值得回应 | 对方夸大自己时继续当前事 | 气息轻、少回应，不堆冷笑挑眉翻白眼 |
| 失望 / 还是这样 | 等待的行动未发生，收回机会 | 放下等待姿势，句子短，不自动变愤怒 |
| 愧疚 / 想补偿 | 看见后果，先做可兑现的小事 | 不抢解释，等接受与否，未被原谅不释怀 |
| 释然 / 不用撑着了 | 威胁解除或被理解 | 呼气先于笑，撑桌的手松开，疲惫仍在 |
| 欣喜 / 真的吗 | 确认好消息细节后行动 | 语速渐活跃，把消息落实到一件事 |
| 关切 / 给你余地 | 看见窘境，给选择而非逼问 | 降低身体压迫，递物等回应，不强迫接受 |
| 坚定 / 代价我来担 | 看清代价后作出选择 | 完整稳句，站姿支撑动作，随即兑现承诺 |

“你先走”可表示保护（挡住来路）、逐客（让开门口收回目光）、逞强（攥着对方留下的物件）或克制的请求（等对方看过来才说）。依据事件与关系选择。
复合情绪只留有辨识度的破绽，如生气却护住对方物件；不逐项填满眼神、面部、身体、手指、声线、呼吸。反应不必轮流换主导轨。
