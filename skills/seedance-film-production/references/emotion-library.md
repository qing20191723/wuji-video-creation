# 事件驱动的表演系统

只在需要表演设计、情绪会诊或微表演备选时读取。情绪名是选材入口，不是镜头指令；最终只写观众能看见或听见的行为。外部“100种情绪”等资料只可作为别名索引，不整表复制，不把固定 15 秒、固定轨道秒点或肌肉编码带入成品。

## 1. 从事件开始

每条 `performance_arc` 先回答四件事：人物此刻要什么；什么可见/可听事件触发表演变化；变化前的状态还残留什么；片段结束后什么残留会进入下一段。没有事件触发就不安排表情变化，不能为了“细腻”让脸部持续做无因微动作。

强度只使用 `subtle / restrained / clear / explosive` 四档。强度由利害关系、遮掩成本和身体负荷决定，不按时间自动升级，也不要求六轨同时拉满。

## 2. 六轨表演

从下列六轨中选择最少充分的活跃轨，其他轨保持自然：

- `gaze`：注视对象、避视、重新聚焦、视线落点与持续时间；
- `face`：眉眼、嘴角、下颌、吞咽或泪水等可见变化；
- `head_shoulders`：转头、下巴角度、肩颈收放及面对/回避关系；
- `hands_objects`：手的落点、抓握、松开、失败动作和物件反馈；
- `body_weight`：支撑脚、前后移、坐立依靠、距离与退路；
- `breathing_sound`：呼吸路径、节律、停顿、破音及可追溯的非语言声音。

不要把六轨打印成字段拼接的导演稿。内部先选轨，最终把它们写成一个因果连续的动作句；同一信号已经足够时，不再叠加同义反应。

## 3. 转换和残留

情绪转换必须同时记录：

1. 原状态残留：旧情绪在呼吸、姿态、手部或视线中留下什么；
2. 转换开关：一句话、一个接触、一个声音或新信息如何打断旧状态；
3. 新状态接管：先由哪一轨改变，再如何影响其余必要轨；
4. 片段残留：结束时尚未恢复的信号如何交给下一片段。

跨镜不能让呼吸、泪痕、手部压力或身体支撑瞬间归零。若人物有意伪装，写清“表面控制住了什么”和“哪一个泄露信号仍在”。

## 4. 复合情绪

只采用“一个主导情绪 + 一个泄露信号”。主导情绪控制人物的行动选择和主要轨道；次级情绪只能从一个具体破绽泄露，例如声音轻微发紧、手没有立即松开或视线晚半拍移开。禁止五五开、同一部位互相抵消、把多个情绪名串成形容词链。

## 5. 多人物反应链

多人同场时，不要让所有人同时表演同一种情绪。按事件因果组织最短可读链条：一人发起可见行动或说出关键话语，另一人先察觉并出现最小回应，发起者读到回应后才调整策略；第三人只有在确实看见、听见或承担后果时进入反应链。

每个反应都要说明可感知来源，避免“全员同时震惊”。切换观看对象也跟随这条反应链：当前机位已经能同时读出发起与回应时不切镜，只有回应被遮挡、关系变化或新信息需要独立观看时才改变位置。

## 6. 别名选材索引

按事件功能查找近义情绪，不按编号套用：

- 接近与开放：欣慰、释然、信任、期待、窃喜、温柔；
- 抵抗与压抑：隐忍、戒备、克制、嫉妒、委屈、羞耻；
- 威胁与高唤醒：愤怒、惊恐、警觉、厌恶、决绝；
- 失落与低唤醒：忧郁、绝望、疲惫、麻木、悲悯；
- 认知变化：错愕、困惑、顿悟、怀疑、专注、敬畏；
- 社会表面与内里：讨好、尴尬、轻视、傲慢、伪装镇定。

选中别名后仍须回到事件、六轨、强度和残留，不直接复制典型表情。

## 7. 输出检查

- 表演变化是否由事件触发，而不是按秒点自动发生；
- 是否只有必要轨道在动，且动作能被镜头看见或声音捕捉；
- 复合情绪是否只有一个次级泄露信号；
- 台词、动作、镜头和声音是否共享同一强度弧线；
- `residual_state` 是否进入 `transition_ledger` 或下一段起始状态；
- 多人物场景是否形成“发起—察觉—回应—调整”的可感知链条，而非同时做表情；
- 批量修订是否核对了全部受影响片段，没有只改第一个命中项；
- 删除情绪名后，观众是否仍能从行为读出人物选择。
