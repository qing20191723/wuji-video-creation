# 剧本优化、人物真实感与自适应文戏

## 1. 来源保真

- 完整读取小说、剧本、想法和已确认材料。
- 锁定人物关系、事件顺序、关键台词、明确OS、核心道具、胜负和情绪落点。
- 已确认分段或台词不得因内部估算擅自重切。
- 原文空缺只做最低限度补足：目标、阻碍、行动路径、空间地标、触发器、出口。

## 2. AI可生成剧本

这一阶段先解决“人物和事件是否成立、是否可被稳定拍出来”，不提前解决“每个镜头怎么拍”。用户可能只给一句想法、文学化小说段落、剧情梗概、舞台式对白、缺少空间因果的脚本，或包含大量心理与概述的故事。先改写成完整剧本并等待确认，确认后才进入按戏剧单元分段与分镜。

### 2.1 不可生成问题诊断

只报告会影响生成的实质问题：

- 人物目标、阻碍、失败代价或策略变化缺失；
- 场景时间、空间、人物入场/离场或事件顺序不清；
- 关键行为只存在于心理、旁白或背景介绍中，画面没有证据；
- 动作缺少起因、过程、反馈或结果；
- 对白没有明确说话人，OS与画外音混淆；
- 新人物、能力、道具或信息凭空出现；
- 同一场承担过多地点、时段或核心转折，无法稳定连续生成。

不要为了显得专业而罗列无关问题。输入本身已经可生成时，明确说明“结构可用，仅做影视化整理”。

### 2.2 优化剧本最小结构

G1交付的优化剧本按场组织，不写镜号与时间码。每场至少交代以下事实；短场可合并成自然剧本文本，不为填字段扩写：

```text
【场次ID｜内/外景｜地点｜时间】
出场人物：
场景初始状态：人物位置、关键环境、核心道具
人物目标与阻碍：
可见剧情：按因果顺序写动作、反应、道具变化和空间变化
对白/OS/声音：说话人明确；原作锁定台词与OS逐字保留
本场转折：什么信息、行动或决定改变了局势
本场出口：人物、关系、道具和环境停在什么状态
```

简单想法过短时可以补足最低限度因果桥，但必须在【改编说明】中逐条标记为“建议补足”，不能伪装成用户原设。存在多个会改变主题、结局或人物动机的合理方向时，不擅自选定；提供简短分支并等待用户选择。

### 2.3 G1交付边界

G1只交付：来源锁定、不可生成问题诊断、完整优化剧本、改编说明、待确认假设和自检摘要。禁止在同一轮输出镜头编号、景别、运镜、时间码、分段表、资产提示词或Seedance提示词。用户确认后，将该剧本绑定到当前revision，G2只能从这版剧本拆解，不重新概括故事。

每场先回答：

`人物想要什么 + 谁/什么阻止 + 失败会怎样 + 怎样改变策略 + 本场结束时什么改变`

转换方法：

- 内心判断→视线、选择、犹豫、未完成动作、道具或距离；
- 背景介绍→场景证据、冲突对白、环境声音或必要短OS；
- 大段叙述→有起因、过程、结果的可拍事件；
- 抽象形容→光线、材质、速度、身体反应；
- 重复解释→保留一次最有戏剧功能的呈现。

不要把所有心理都改成动作：原作明确的第一人称心声、OS、内心独白必须逐字保留；没有形成明确话语的心理叙述才转成画面。

## 3. 开幕钩子与Squeeze

继承公开钩子技能的优点，但不机械套模板：

- 需要短视频钩子时，开场尽快给出与核心困境直接相关的可见事实；电影感、慢节奏或用户已有开场时不强加 Highlight Shot；
- 尽快让观众读懂人物目标；
- 目标刚建立，阻碍立即产生可见压力；
- 角色找到出口时，让阻碍从信息、时间、关系、资源或空间至少一项升级；
- 每次挤压必须迫使人物改变行为，不能只提高语气；
- 结尾留下由前文因果产生的追问点，不凭空出现隐藏BOSS或新秘密；
- 不硬性要求固定秒点反转，不把开幕短剧规则机械覆盖所有文戏。

目标可来自生存、保护、复仇、救赎、逆袭或追寻；阻碍可来自外部、内部、关系或信息。选择最符合原文的一组，不为套分类修改故事。

## 4. 去AI味台词

- 新增台词负责施压、试探、拒绝、澄清或决定，不负责解释全部背景；
- 长短句错落，允许打断、反问、抢话、吞回去和留白；
- 抽象词换成具体事实和即时选择；
- 不让角色直接说“我很愤怒/我很悲伤”；
- 古装使用自然古白话，现代口语真实，悬疑少说多看，动作短句明确，科幻术语自然嵌入；
- 用户指定台词和明确OS逐字保留，新增台词不得挤掉原作台词。

## 5. 戏剧单元与时长

先按“一次可见的关系状态变化”确定戏剧单元，再估算可自然表演的时长；不按字数平均，也不为了填满模型上限增加内容：

- 一段一个主场景、一次主要关系变化、一个明确出口；
- 优先在决定、拒绝、离场、信任建立、信息揭示或新行动开始处收尾；
- 不在完整台词中间切段；
- 按实际台词、停顿、走位和动作试读估算；压抑、迟疑、方言或复杂动作应留出更多时间；
- 超过当前模型入口上限时在真实关系转折处拆段，禁止整体加速硬塞；明显不足时保留短段，不注水补齐。
- 每段记录 `dramatic_unit`、`duration_seconds` 和 `duration_rationale`。时长是对已成立内容的估算，不是先验模板。

## 6. 文戏观看设计

- 先写完整事件、表演和空间流，再选择最少充分镜头；不设最低镜头数；
- 一个长镜头能承载关系变化时不拆；空间、权力、注意力或关键信息改变时才考虑切镜；
- 不用眨眼、吞咽、抬手、道具特写或单纯视线移动制造虚假密度；
- 一个镜头至少承担新信息、新决定、距离变化、道具变化、情绪触发、关键反应或完整一轮对白；
- 删除一个镜头不影响信息、关系或决定时，合并或删除。

每段记录 `shot_count_rationale`：为何这些切镜不可由更少镜头完成。单镜、少镜和多镜均可通过。

## 7. 表演弧线

- 先找人物此刻的策略与防御方式，只记录真正发生变化的状态，不设状态数量；
- 对手的反应来自听见、误解、躲避或决定，不为形成整齐回声而存在；
- 第三角色只承担揭示、打断、见证或推动决定；
- 每镜只写必要的可见信号，零个、一个或多个均可；
- 保留泪痕、眼红、呼吸、未松开的手和未完成转身等跨镜痕迹；
- 全片留若干不完整动作或表情，避免AI式过度完成。

只有用户明确要求微表演诊断时才读取 `emotion-library.md`。词库只能提供候选，不能决定人物反应；交付层全部翻译为当前处境中的白话电影语言。

## 8. 对白、OS与画外音

- 对白轮数与句长由人物、关系和表演时长决定，不设默认数量；
- 一句完整台词默认在一个镜头内自然说完；
- 若使用L-cut/J-cut跨视觉镜头，音轨必须连续、只出现一次，在下一镜标记“角色名画外音继续”；
- `角色名OS`只用于原作明确内心声；同场角色暂时出画仍说话是“画外音继续”，不是OS；
- 每一时刻只允许一个说话者，倾听者闭口并给出可见回声；
- 声线锁定后逐字复用，当前情绪只改变语气、呼吸与音量，不改基础声线。

## 9. 场面调度、切镜与空镜

- 先建立人物站位、180度轴线、视线和核心道具初始状态；人物站位不是镜头；
- 镜头1从站位启动第一个真实动作、台词或环境事件；
- 只有信息、权力、距离、目标、道具、声音或动作路径变化时切镜；
- 运镜和切镜只为观看关系服务；稳定机位、长镜头、过肩、正反打、反应、插入或空镜都不是默认配额；
- 过肩前景人物闭口，台词结束后才切关键反应；
- 插入镜头仍有人物局部；空镜人物完全出画，只承接上一镜已经启动的动作、声音或物理后果；
- 空镜不能凭空生成水滴、摆动、脚步或声响。

## 10. 道具状态机与跨段复位

默认一个核心道具、至多一个次级内容物。逐镜记录：

`持有者 → 左右手 → 方位 → 朝向 → 开合 → 数量 → 交接启动 → 运动过程 → 落点`

每段末提取人物位置、姿态、视线、离场空位、道具、门窗、光线和环境声。下一段在镜头1前重新写出具体站位，不能只写“承接上一段”。
