# 正常剧本十六宫格故事板

仅为 `content_lane=normal` 的完整生产任务读取。十六宫格承担“把已批准剧本、分镜与资产压成一张可验收的视觉合同”的职责，不承担重新创作剧情，也不代表最终视频必须有 16 个镜头。

## 1. 前置条件

进入本阶段前必须具备：

- 当前 revision 的正常剧本与最少充分分镜已经批准；
- 人物、场景、道具和必要 VFX 资产已经生成、看图并批准；
- 每个故事板状态都能追溯到正常剧本的 `source_span_id`、场次和镜头/动作相位；
- 人物身份、服装、道具、光向、轴线、起止状态和跨段接口已经锁定。

没有已确认资产时只输出十六宫格图片提示词和待绑定清单，不虚构“参考图1”。用户已经提供并确认资产图时，优先引用这些资产；未验收图不得进入正式故事板。

## 2. 16 格不等于 16 镜

4×4 画布固定有 16 个等大横向画格，按左到右、上到下阅读。先从已批准正常剧情提取 16 个“有独立视觉价值的状态”，再映射到画格：

- 同一个长镜头可以占多个画格，但每格必须是该镜头中不同且有因果价值的起始、转折、接触、反应或结束相位；
- 一个视频镜头也可以只占一格；
- 不因换台词人、眨眼、吞咽、抬手、道具露面或单纯景别变化自动占一格；
- 不新增空镜、路人、反应、慢动作、重复构图或无来源动作填满版式；
- 全部正常剧情确实不足 16 个有效状态时，先扩大这张板覆盖的正常场次范围；仍不足时明确报告“现有剧情不足以诚实形成十六宫格”，回退 G2，而不是伪造状态。

每格登记：

`格号 → source_span_id → scene_id → shot_id/phase → 主体与可见事件 → 起止状态 → 资产ID → 与前后格的连续关系`

## 3. 十六宫格图片提示词

对外提示词必须是一段完整自然语言，不输出“人物/场景/镜头/光线”字段拼接。提示词先绑定每张真实参考图的唯一职责，再说明整图版式与共同锁定，最后按阅读顺序自然描述 16 格的静态结果。

可复用的写法骨架：

```text
参考图1（角色A定妆）只锁定角色A的面部、体型、妆发与服装，参考图2（角色B定妆）只锁定角色B，参考图3（场景母版）只锁定空间结构、材质和光向。生成一张16:9横向4×4十六宫格电影故事板，16个等大横向画格以极细白线分隔，无外框、标题、编号、对白框、字幕、水印和Logo，按左到右、上到下呈现同一段连续剧情。所有画格保持已批准人物身份、服装、场景地标、光向、轴线和道具状态一致；第一格呈现……，第二格顺接……，……，第十六格停在……。每一格都是对应动作相位的清晰静态电影画面，前一格的动作结果、人物位置、视线、服装和道具状态必须成为后一格的起点，不增加剧本和分镜之外的人物、动作或物件。
```

成品中仍要把省略号替换为 16 格逐格具体内容；可以使用“第一格、第二格……”帮助图像模型建立顺序，但画面内不生成可见编号。

## 4. 图片生成

- 当前工具支持多图参考时，把已验收人物、场景、道具资产全部作为真实输入，并在提示词中逐一说明职责；
- 工具不支持足够参考图时，优先保留人物身份和主场景母版，不能静默丢弃核心资产；
- 生成后必须查看真实像素；若分辨率不足以看清单格，先放大或切片检查，再验收；
- 返修时以完整故事板为编辑目标，只改失败格，并复查未指定画格没有漂移。

## 5. 视觉验收

逐格检查：

- 是否与 `BOARD_MAP` 中的 16 个状态一一对应，没有错序、缺格或重复格；
- 角色显隐、面部身份、年龄、体型、服装、配饰与资产一致；
- 场景地标、光向、轴线、屏幕方向和人物左右关系连续；
- 动作因果、手脚位置、重心、道具持有者和状态可读；
- 前格结果是否成为后格起点；跨场时是否有批准的转场依据；
- 无文字、水印、Logo、额外人物、融合、多肢、畸形手和背景重构。

只有实际图片通过验收，才登记为 `BOARD-Nxx` 并进入 Seedance 2.5 编译。

## 6. 与 Seedance 2.5 的关系

视频提示词使用一张或多张已验收十六宫格作为构图与状态参考，但仍按实际可拍时长和最少充分镜头编译。不要把 16 格逐格机械变成 16 次切镜，也不要在提示词中按相同时长平均分配每格。每个生成片段只引用它实际使用的画格范围，并写清从哪个动作相位展开、在什么状态结束。
