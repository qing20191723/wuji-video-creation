# 宫格分镜图：彩色或黑白线稿（旧文件名保留为兼容入口）

依据已确认分镜和实际资产生成。用户在资产审阅时选择彩色或黑白线稿；此前已指定则直接沿用。两种形式共用同一映射、依赖和第四次成果确认，不先生成另一种作为必经中间产物。
- **黑白线稿 / black_white_lineart**：黑或深灰轮廓线、白背景、少量浅灰表现空间。
- **彩色 / color**：继承资产的身份、服装、材质与颜色，呈现分镜所需光色；具体写实或绘画风格沿用项目要求，不因选择彩色自动换画风。
共同要求：细分格线，人物关系与动作清楚；无画内编号、对白框、水印和无关文字。资产本身的必要服装图案不当作新增标注。
宫格锁构图、位置、动作状态及顺序，彩色板可补充光色，但不得重设资产身份或服装。黑白板不决定成片必须黑白。

## 内容决定版式

先列 panel ID → shot ID → 关键状态的图外映射，再排版。格数不固定4/6/9/16，一镜可多格，格数不等于切镜数。
单格继承项目画幅；板宽=最大列数×单格宽，板高=行数×单格高。不足整行采用短行，剩余区域为纸边，不画空白格、不填剧情。
5格可用 row_lengths=[3,2]；16:9单格整板外接比例48:18。工具不能可靠生成短行时改为3格、2格两页，映射不变，不补空镜。
过密则按场景或连续事件分页，末页不填充。跨页继承道具归属、人物位置和动作结果。
生成描述先明确所选视觉形式和布局，再顺序写每格静态结果。给工具真实资产和各自职责，不传不相关素材。

## 验收与编辑

逐格核对身份、服装、人数、姿态、轴线、左右、受力、手持物、动作相位和结果，再核对图外映射、无新增文字和实际所选形式；彩色板额外核对肤色、服装颜色及日夜光线，黑白板检查灰阶与轮廓可读性。
优先编辑整张原图的问题格，之后复查全板；失败保存旧版与问题，标 blocked，不能用提示词自检顶替图片验收。
第四次确认实际图后直接编译，无独立宫格提示词审批。
