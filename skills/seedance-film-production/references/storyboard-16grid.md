# 正常段十六宫格

仅为 `content_lane=normal` 的完整生产读取。它把批准的叙事段落、分镜和资产压成视觉合同，不重新创作，也不代表 16 个视频镜头。

## 覆盖范围

先完成实际分镜，再判断一张画板覆盖一个或多个相关叙事段落。人物关系、空间逻辑、故事阶段或视觉信息已经无法在同一板清楚表达时重开；不按“每段一张”或“每场一张”固定分配。

一张 16:9 横图包含 4×4 等大横向画格，按左到右、上到下阅读。每格来自批准的 `source_span_id`、片段和镜头/动作相位。同一长镜头可占多格，但状态之间应有因果价值；不因台词换人、眨眼、道具露面或景别变化自动占格。

有效状态不足时先扩大画板覆盖的相关正常段落；仍不足则回退 G2，不新增空镜、路人、反应、慢动作或无来源动作。新叙事段落的首个状态体现 `reentry_plan`，末状态体现 `completion_cue`。

每格登记：

`格号 → 来源/片段/镜头相位 → 可见事件 → 表演状态 → 观察位置 → 光影 → 起止状态 → 资产ID`

同一 `BOARD-Nxx` 可被多个正常片段引用；成人片段不得引用。

## 图片提示词

对外输出一段自然语言：先说明真实参考图的唯一职责，再锁定 4×4 版式、共同人物/场景/光影，最后按顺序描述 16 个静态结果。可以用“第一格……”建立生成顺序，但画面内不出现编号、文字、对白框、水印或 Logo。

前一格的动作结果、位置、服装和道具成为后一格事实。跨叙事段落时，后一格可以重新选择观察位置，但必须恢复同一世界状态并启动新的入场动作。不得把内部表演字段或摄影清单打印为提示词。

## 生成与验收

使用当前 revision 已验收人物、场景和道具资产；不足时只输出提示词与待绑定清单，不虚构引用。生成后实际查看像素，必要时放大或切片检查；返修完整画板中的失败格，并复查其他格未漂移。

逐格核对映射顺序、身份、年龄、体型、服装、地标、光向、轴线、人物左右、动作因果、手脚/重心、道具持有与状态，以及无文字、额外人物、融合或畸形。通过后登记 `BOARD-Nxx`。

Seedance 每个片段只引用实际使用的画格范围。宫格提供构图和状态参考，不能逐格机械变成等时长切镜。
