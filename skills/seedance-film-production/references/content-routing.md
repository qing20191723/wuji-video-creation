# 正常/成人双轨路由

同一输入同时含普通剧情与成人内容时读取。本文件只决定来源跨度走哪条生产链；边界由 `adult-intimacy.md` 管理，叙事换段由 `narrative-direction.md` 管理。

## 来源跨度

通读全文后建立 `SOURCE_SPAN_LEDGER`：

`span_id → source_order → 稳定起止位置 → 事件摘要 → normal/adult → 场次/片段 → 理由`

- `normal`：剧情、对白、情绪、战斗、生活动作、非性行为亲密及成人行为前后的普通叙事；
- `adult`：已批准的性化裸露、明确性接触/行为及与行为不可分割的回应、停止和结果。

每个允许处理的跨度有且只有一个路由。边界句按主要可见事件归类；确实包含两个先后事件时拆成两个不重叠动作单元。不可处理跨度保留 ID 与阻断原因，不静默删除。

## G1 生产视图

保持一份全片 Canon，同时交付正常剧本、成人剧本和两路进出口状态。成人跨度不能被“一番亲密”、黑场或无因遮挡替代；两份视图不改变原始时序。

## 跨路由叙事移交

正常→成人停在最后一个普通行为，成人段从第一个已批准明确行为开始；成人→正常继承实际停止/接续结果。边界事件不重复、无缺口。

`transition_ledger` 记录上一段完成意义、前向冲动、下一段再入场锚点及人物、身体支撑、覆盖、道具、光影、声音、关系和同意状态。普通换段允许重新选择摄影机；精确动作确需连续且两路都可使用时才生成中性共享关键帧，否则使用 `state_only`。

## 产物隔离

| 路由 | 产物 | 不生成 |

| `normal` | 剧本、正常分镜、资产、十六宫格、Seedance 2.5 提示词 | 成人 Wan 提示词 |

最终确认所有跨度均能追溯到唯一片段、路由和模型，相邻片段均有唯一叙事移交。
