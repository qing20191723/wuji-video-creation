# 叙事段落与镜头再入场

G2 分段、正常分镜、成人动作段落和 G7 提示词都以本文件为创作事实源。目标不是预先剪辑文件，而是让故事本身形成可以独立生成的叙事段落；顺序组合自然成立是结果，不是创作起点。

## 1. 叙事段落

一个片段只负责讲清一层意思：一次发现、试探、回应、决定、关系变化、动作阶段或结果。它不必拥有完整起承转合，也不因模型可生成 30 秒就扩写。

先填写 `narrative_paragraph`：

- `meaning`：观众看完本段应真正理解什么；
- `development`：哪些人物选择、行为、反馈或环境变化让意义成立；
- `completion_cue`：哪个可见或可听结果表明这一层已经讲完；
- `forward_impulse`：什么尚未执行的意图、问题或后果把故事推向下一段。

当意义已可读、人物到达新状态、继续观看只会重复时结束。意义仍在形成时，即使出现换位、停顿或一个漂亮物体，也不要拆段。超过模型入口上限时，才在真实完成信号或新的故事问题处拆开。

## 2. 重新入场

新段落像小说另起一段：摄影机结束上一次观看，再为新意思选择入口。`reentry_plan` 记录：

- `anchor`：人物、动作、前段结果、剧情物体、空间关系或当前段内有来源的声音；
- `opening_action`：新段落真正开始的第一个行为；
- `inherited_state`：为了不让世界重置而需重申的状态；
- `first_new_information`：入场后观众首先得到的新内容。

入场应尽快让人明白仍在何处、谁仍在场、上段留下什么、现在开始什么。它可以从已经开始的新动作、前段后果、故事物体、人物间距、空间或声音进入；这些是选择，不是轮用模板。全景不是默认入口，局部也不能故意隐瞒理解当前行为所需的空间。

物体只有在剧本中已经存在并承载人物行动或注意力时才可作为入口。它像段落铰链：先让观众重新找到问题，再带出人物；不是为了展示转场技巧。

## 3. 连续的是故事世界

跨段继承人物身份与身体特征、声线、场景时间和光源、服装/覆盖、道具与损耗、已完成行为、合理身体起点、情绪与呼吸残留、人物意图和关系结果。成人段还继承接触、支撑、遮挡、镜头边界和持续同意。

摄影机位置、景别、焦点、运动和段内镜头数可以重新选择。普通换段不要求尾帧与首帧匹配；只有未完成动作必须无缝延续时，才锁精确方向、姿态或边界帧。不要把“承接上一段”当状态描述，写出下一模型实际需要知道的事实。

`transition_ledger` 是叙事移交：上一段完成的意义与前向冲动，应分别对应下一段的再入场锚点和首个新动作。它不要求摄影机沿原轨迹继续。

## 4. 摄影机怎样讲故事

先让人物与环境发生变化，再决定观看如何回应：

`事件改变 → 注意力改变 → 摄影机响应 → 新意义被看见`

跟随人物要带出新空间、阻碍或关系；靠近要让决定、迟疑或信息获得新的距离；离开要显出孤立、后果或空间关系；焦点转移要交接故事主导权。固定观看也可以成立，让沉默、等待或关系变化在构图内发生。

`camera_plan` 只记录：

- `entry_view`：本段如何进入观看，并与 `reentry_plan` 一致；
- `attention_progression`：注意力随故事怎样推进；
- `viewpoint_turns`：仅列真正改变理解的变化，每项写固定枚举 `response_type`、自然语言 `trigger / camera_response / revealed_meaning`；没有变化时用空数组；
- `closing_view`：本段结束时观众最后看懂什么。

`response_type` 使用 `static / descend / pull-back / push-in / pan-tilt / follow / lateral-track / ascend / focus-shift / other`。这是摄影响应，不是效果清单。每段还以 `composition_plan` 记录主导点、对比方式、引导线、前中后景、留白、视觉重量和起止画面；以 `camera_plan.continuity` 记录轴线侧、视线目标、屏幕方向及入/出镜的动静状态。

摄影机响应可以是移动、切换、焦点变化或保持不动。术语不能单独构成 `camera_response`；删掉术语后，触发与揭示仍应成立。轴线、屏幕方向和光影技术连续读取 `cinematography.md`。

## 5. 提示词成为影视叙述

正文从具体环境中的人物和动作开始，不先宣布镜头、时长或摄影参数。随着人物移动、注意力转移、遮挡打开或关系变化，观看位置自然进入句子；每次变化都落到观众新看见的事实。段尾停在 `completion_cue`，并留下 `forward_impulse`，不额外预演下一段。

下一条提示词重新建立必要状态后立即开始新动作，不重复完整人物小传、场景介绍或上一段剧情。人物和静态世界主要由已验收资产继承，正文只重申高风险不变量和时间中的变化。

时间戳只解决复杂因果定位；内部字段、动作族、情绪轨和镜头清单不能原样打印。删除摄影句后，人物在做什么以及故事怎样变化仍应清楚；删除人物行动后只剩摄影术语，则需重写。

## 6. 成人叙事段落

成人段也按关系或行为意义分段，而不是按动作词逐项切开。发起与回应、主动性或情绪改变、真实行为阶段、支撑/覆盖重建、暂停/停止/重新确认或事后结果，只有在它们改变故事理解时才形成新段落。

重新入场先恢复同一人物、身体特征、裸露/覆盖、双方位置与支撑、呼吸声音、情绪和持续同意，再开始新的已批准行为。摄影机可为新阶段重新选择观察位置，不机械匹配尾帧；不得把身体切成无关系的局部清单，也不能用遮挡抹掉原文事件。

Wan 默认使用已验收人物、场景和状态资产保持世界连续；精确姿态确实决定动作起止时才选择首帧或首尾帧。具体边界和动作分别读取 `adult-intimacy.md` 与 `adult-choreography.md`。

## 7. 人工复核

- 本段能否用一句具体话说明“讲清了什么”，而不是只说“推进剧情”；
- 完成信号是否已经发生，还是为了分段提前截断；
- 新段是否重新进入同一世界，而非重复介绍或状态复位；
- 每次观看变化是否让观众多理解一层；
- 多段顺序阅读时，前段结果是否成为后段事实，同时每段又能独立投喂模型。
