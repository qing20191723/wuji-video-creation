# 故事覆盖、镜头再入场与直拼单元

G2 分段、正常/成人分镜和 G7 提示词以本文件为创作事实源。目标是让每个独立生成单元讲完一层故事，并让相邻单元组合后产生连续因果；不是先设计剪辑花样。

## 1. 叙事段落

一个单元可以完成一次发现、试探、回应、决定、关系变化、动作阶段或结果。填写 `narrative_paragraph`：

- `meaning`：观众看完真正理解什么；
- `development`：哪些选择、行为、反馈或环境变化使它成立；
- `completion_cue`：哪个可见/可听结果表明已经讲完；
- `forward_impulse`：尚未开始的意图、问题或后果怎样指向下一段。

意义仍在形成时不因换位、漂亮物件、固定秒点或模型上限临近而提前切碎；意义已可读、人物到达新状态、继续观看只会重复时结束。超过入口上限才在真实完成信号或新故事问题处拆开。

## 2. 先覆盖故事，再补视点

先找一个能承载主要行动、空间关系和结果的“主观看位置”，写入 `camera_plan.entry_view`。让场面在这里尽可能连续发生；主观看位置已经讲清剧情时，不为获得远/中/近组合、填宫格或显得专业而补镜。

只有观众的理解需要改变时才加入 `viewpoint_turns`，其功能限于：

- 揭示：此前不可见的事实现在必须出现；
- 反应：一个人的反应改变了另一行为的意义；
- 悬念：先让人物或环境反应成立，再在恰当时机揭示原因；
- 强调：某个决定、接触或结果需要重新分配注意力；
- 空间重建：位置、方向、阻碍或行动路线已经改变。

每项使用 `trigger → camera_response → revealed_meaning`，并以 `response_type` 记录机器可查的响应类别。动作、道具、视线或声音可以成为注意力载体，跨越多个视点保持问题连续；载体一旦不再提供信息，就回到人物选择，而不是继续追拍物体。

`composition_plan` 只保留 `dominant_point / attention_path / depth_and_balance / start_frame / end_frame`。这些值要能画成草图：注意力从哪里起、被什么带到哪里，前中后景和遮挡如何共同服务当下故事。不要写“电影感、点线面、高级构图”。

## 3. 重新入场与世界继承

下一段像小说另起一段：结束上一次观看，再为新意思选择入口。`reentry_plan` 记录 `anchor / opening_action / inherited_state / first_new_information`。锚点可来自人物、动作、前段结果、已有物体、空间或当前单元内有来源的声音；它必须迅速让人明白仍在哪里、谁在场、继承了什么、现在开始什么。

跨段强制继承人物身份/体型/声线、场景时间与光源、服装/覆盖、道具与损耗、已完成行为、合理身体起点、情绪/呼吸残留、人物意图和关系结果。成人段还继承接触、支撑、遮挡、呈现边界和持续同意。摄影位置、景别、焦点和运动可重选；仅当未完成动作必须无缝延续时才锁精确方向、姿态或边界帧。

## 4. 摄影参与叙事

摄影变化遵循：`事件改变 → 注意力改变 → 摄影响应 → 新意义被看见`。跟随带出新的空间、阻碍或关系；靠近让决定或信息获得更近的观看距离；离开显出后果或孤立；焦点转移交接故事主导权；固定观看让沉默、等待或关系变化自行发生。

摄影术语不是句子主角。写“她把信封推过桌面，画面沿桌沿跟到对面停住的手，直到那只手没有接”，不要写“中景，横移镜头，作用是表现拒绝”。删掉摄影表达后，人物仍在完成清楚行动；保留摄影表达时，它应让观众多理解一层。

轴线、视线或方向确有连续风险时，`camera_plan.continuity` 记录具体空间关系；不存在问题时写 `not-applicable`，不要制造假字段。技术连续与光影读取 `cinematography.md`。

## 5. 直拼与蒙太奇

每个相邻单元用 `transition_ledger.assembly_contract` 说明 `join_mode / visual_join / sound_join / combined_meaning`：

- `straight-cut`：上一段的完成结果直接成为下一段的事实；画面和声音在切点各自完整。
- `shared-boundary`：未完成动作确需精确边界时共享合法首/尾状态资产。
- `montage-cut`：两画面组合出单独画面没有的第三层含义；可选记录 `narrative-compression / rhythm / contrast / parallel / expressive`。

叙事压缩跨过重复过程；节奏关系以动作或声音模式组织时间；对比让差异产生判断；平行让异地/异时行动互相解释；表现性组合外部画面与主观感受。类型不是通行证，`combined_meaning` 必须说清新增了什么；“更顺滑、过渡一下、避免跳切”无效。

跨独立单元的直接拼接不能假装存在 J/L 音轨重叠。使用匹配环境底声、明确声音落点、静默切口或双方共享的声音参考；J/L 只用于同一生成单元内部，或用户允许后期重叠时。

## 6. 视频提示词是正在发生的场面

外部制作卡登记 ID、模型、时长、画幅、输入模式、真实引用、revision 和字符数；它不属于投喂模型的正文。正文从环境中的人物和正在发生的动作开始，随后按因果写行为、回应、对白与同步声音。摄影随着注意力自然进入句子，停在 `completion_cue`，留下但不预演 `forward_impulse`。

不要以“镜头/景别/运镜/灯光/时长”开头，不打印内部字段，不把一个动作拆成术语列表。时间戳只在复杂并发或严格因果定位时使用。下一条提示词重申高风险连续状态后立即开始新动作，不复述人物小传、整个场景或上一段剧情。

## 7. 成人段与人工复核

成人段仍按关系或行为意义分段，具体边界与动作读 `adult-intimacy.md` 和 `adult-choreography.md`。主动性、同意、真实行为阶段、支撑/覆盖重建、暂停/停止或事后结果改变理解时才另起段；不按动作名词逐项切开，也不以遮挡省略批准事件。

复核：一句话能否说清本段讲了什么；主观看位置是否已足够；每个补充视点是否增加信息；悬念是否先建立反应再揭示原因；身份/服装/声音/道具是否复位；相邻单元的画面与声音能否直接切接；删除摄影术语后行动是否仍清楚。
