# Seedance 2.5 正常段最终编译与校验

本规则只编译 `content_lane=normal` 的片段，以 Seedance 2.5 官方公开能力为基线：单次最长30秒，单次最多30张图片、10段视频、10段音频参考，并支持后续延长。实际平台、地区或账号入口低于该能力时，以当前界面为准并把实际限制写入 `model_profile`。成人段改读 `wan3-output.md`，不得混入本编译器。

## 1. 编译前置条件

只有以下项目齐全才进入最终编译：

- 当前revision的AI可生成剧本已在G1批准或被用户明确声明为定稿；
- 当前revision的分段与连续文字分镜已在G2批准；
- 当前片段的镜头表已批准，编号与时间连续；
- 资产提示词、人物定妆、资产图和故事板门禁均已由用户批准；
- 当前正常段使用的 4×4 十六宫格已经真实生成、逐格验收并登记为 `BOARD-Nxx`；
- 资产ID和版本已锁定；
- 需要的实际资产已通过视觉验收；
- 每个正式 `@` 引用真实存在并登记唯一职责；
- start_state来自上一片段end_state；
- 本段关键台词、OS、胜负和末状态明确。
- 当前提示词内图片、视频和音频引用分别不超过 `model_profile` 记录的实际限制，且不得超过官方30/10/10上限。
- 当前片段明确为 `content_lane=normal` 且 `target_model=seedance-2.5`；成人原文跨度没有被误编入该段。

缺一项则退回责任阶段，不在最终提示词中临场补写。

## 2. 导演式信息顺序

`格式 → 引用职责 → 全局锁定 → 故事/战术目标 → 主体动作与表演 → 环境 → 摄影 → 视觉 → 时间轴 → 声音 → 连续性与禁止项`

使用可见、可听、可执行语言，不堆叠空泛形容词。

## 3. 默认输出：自然导演稿

每个片段先用不超过120字说明该段唯一的戏剧/战术变化、实际时长、十六宫格使用范围和观看策略，随后输出一段可直接复制的自然导演稿。按以下顺序自然组织，不逐项打印标题：

`格式与时长 → 实际参考职责 → 人物/场景必要锁定 → 起始状态 → 按因果推进的表演或动作 → 必要摄影变化 → 台词与声音 → 结束状态 → 当前高风险禁止项`

自然导演稿只保留生成所必需的信息。先说明 `@图片N` 中哪一张是十六宫格以及当前片段主要使用哪些画格的构图/状态；全局锁定说一次；一个镜头能完成时不人为拆段；不把16格机械编译成16次切镜；不重复“电影级、细腻、超写实”等评价词。

只有多引用职责容易混淆、复杂动作因果需要排错，或用户明确要求结构化稿时，才使用以下调试格式：

```text
【格式】
精确时长：该段实际时长；16:9；单镜或连续多镜头；中文；视觉路线。

【参考素材职责】
只列实际存在的@图片N、@视频N、@音频N及其唯一职责。

【全局锁定】
人物身份、脸、体型、服装、声线、场景、光向、轴线、左右关系、道具/武器、画风、战损和跨镜状态。

【故事与表演/战术目标】
一句话说明目标、阻碍、利害关系和本段唯一的关系/战术变化。

【固定台词】（文戏有台词时）
按角色列出逐字台词与OS；无台词写“无台词”。

【时间轴分镜】
镜头1｜00:00–00:xx｜景别/机位/运动｜主体｜起始状态→主要动作→表演或接触反馈→结束状态｜“角色：台词”/OS/环境声/音效｜资产ID
镜头2……

【视觉风格】
光线、色彩、材质、镜头质感、写实/CG/番剧程度；参考素材优先。

【声音】
对白、OS、环境底噪、动作音效、空间混响；需要时才加配乐。

【连续性与禁止项】
仅列当前片段的高风险约束。

【下一段继承状态】
人物、服装/伤势、道具/武器、场景、光线和声音尾部。
```

## 4. 单镜写法

文戏：

`起始站位 + 主导动作/完整对白 + 必要表演信号 + 倾听者真实反应 + 道具状态 + 结束姿态 + 下一镜接口`

武戏：

`输入帧职责 + 起始姿势 + 发力顺序 + 轨迹 + 方向/速度 + 接触点 + 目标反馈 + 环境反馈 + 摄影 + 余势 + 下一镜接口`

## 5. 时间与编号

- 前镜终点等于后镜起点；
- 无重叠、无空缺、不写“约”；
- 片段末点等于该段已批准的实际时长，不得超过 `model_profile.effective_limits.duration_seconds`；
- 镜头从1连续递增，无漏号、重号；
- 不设文戏或武戏镜头数量指标；每次切镜必须有独立观看理由；
- 对白能在镜头时长内自然说完，不整体加速硬塞。

## 6. 引用与资产

- `@图片N/@视频N/@音频N`必须来自ASSET_MANIFEST；
- 一份参考只承担登记职责；
- 镜头所列资产ID必须存在并使用正确版本；
- 角色图不覆盖场景，场景图不改角色，动作视频不改外观，摄影视频不改剧情；
- 未生成、未验收或旧revision资产不能进入正式提示词。
- 同一附件只计一次素材数量；引用数量按图片、视频、音频分别统计，超限时先拆分片段或减少非必要参考，不静默丢弃关键资产。

## 7. 声音

- 台词使用中文引号并标明说话人；
- 同一时刻只有一人说话，倾听者闭口；
- OS与同场画外延续分开；
- 环境声有空间来源，动作音效对应接触、材质和距离；
- 默认由 Seedance 2.5 音画一体生成对白、呼吸、环境声与动作声，不另建配音交付；
- 明确要求模型内生成配乐时，说明起点、功能、让位对白位置和结束方式；无必要不加。
- 剪辑阶段 BGM、素材库搜索词和独立音乐 Cue Sheet 不写进纯视频生成提示词，交给 `post-sound.md`。

## 8. 最终禁止项

只列当前片段真正高风险问题，例如身份漂移、左右翻转、越轴、口型错配、倾听者动嘴、道具瞬移、武器换手、战损复原、背景突变、无因新增人物、文字/UI/水印/Logo。不要堆砌与场景无关的负面词。

## 9. 最终Canon差异检查

逐项比较最终提示词与台账：

- 人物ID、资产版本、关系和胜负；
- 每句台词和OS；
- 每镜起止时间、动作目的和末状态；
- 道具/武器左右手、朝向、数量和破损；
- 场景地标、光向、累积破坏；
- 跨段继承状态。
- 成人亲密内容额外比较：参与者、来源授权、同意节拍、内容等级、接触图、支撑面、服装覆盖、遮挡物和镜头禁区。

发现任何新事实或不一致，禁止“顺手修正”。输出差异清单并回退上游。

## 10. 完整交付不是只给提示词

最终生产包仍应包含项目锁定、AI可生成剧本、分段、连续分镜、资产清单/图、验收、引用映射、Seedance提示词和跨段状态。用户明确只要最终提示词时，也先在内部完成上游Canon校验。
