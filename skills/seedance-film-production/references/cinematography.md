# 空间、光影与接合连续

G2 在 `narrative-direction.md` 完成故事覆盖与观看设计后读取。本文件只约束技术连续，不决定分段或换镜数量。

## 空间

`visual_bible` 锁关系轴、视线基线、主体方向和场景地标。新入口可换摄影位置，但人物左右、朝向、视线与行动区仍须可理解；越轴或方向翻转通过人物移动、可见空间重建或明确主观断裂成立。连续观察相同主体与相近构图时，新位置应提供信息、尺度或透视变化；不写固定角度数字，也不插无信息空镜。

`camera_plan.continuity` 仅在轴线、视线、入/出画运动或屏幕方向确有接合风险时使用对象；否则写 `not-applicable`。对象记录 `axis_side / eyeline_target / screen_direction / motion_in / motion_out`。动接动、静接静只是顺滑倾向；动作爆发、反应、停顿、声音落点或叙事转折可以让静动切换成立。

## 构图与摄影响应

`composition_plan` 写具体主导点、注意力路径、空间深度/重量和起止构图。运镜统一按 `事件触发 → 摄影响应 → 新信息显现 → 起止构图`；升降、推拉、摇移、跟随、焦点转移与固定观看都只在改变理解时使用。“电影感”“点线面”“为了转场”不是计划。

## 光影圣经

`visual_bible.lighting` 记录时间/天气、有来源主光、方向与光质、反差、补光、人物背景分离、综合色温、曝光重点、实景灯与材质反应。写可观察结果，不伪造功率、照度、色温或镜头参数。每段 `lighting_state.start/end` 继承光源、方向、色温关系和曝光重点；变化绑定开关灯、开门、车辆、天气或时间等可见事件。参考 [ARRI Lighting Handbook](https://www.arri.com/en/learn-help/lighting/lighting-handbook)。

## 接合检查

`assembly_contract` 只记录故事单元怎样组合：直切、共享边界或蒙太奇。视觉接合说明前段末结果与后段首个新信息的关系；声音接合使用可在独立文件边界成立的环境底声、声音落点、静默或共享参考。跨模型只有精确动作连续确有必要时才用共享中性关键帧；普通换段使用完整状态移交。

检查新入口是否重建必要空间、方向改变是否有依据、光源变化是否有事件、接合是否新增故事理解而非隐藏错误。
