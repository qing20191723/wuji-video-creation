# 镜头与光影 Canon

在 G2 建立镜头计划和光影圣经时读取；G6 十六宫格和 G7 双模型编译只继承、压缩，不重新发明。摄影术语必须服务于观看理由，不能以运镜、焦段或灯光名词堆出“电影感”。

## 1. 镜头计划

每个片段的 `camera_plan` 至少明确：

- `watching_reason`：观众此刻必须看见的选择、关系、空间或动作结果；
- `axis_side / eyeline_map / screen_direction`：关系轴、视线落点和主体运动方向；
- `framing_and_perspective / camera_height_and_angle`：景别、透视和机位如何改变权力、距离或动作可读性；
- `movement / movement_motivation`：摄影机怎么动，以及由什么事件触发；
- `focus_path`：注意力从哪里转到哪里；
- `cut_reason`：何时出现新的观看价值；
- `end_composition`：交给下一镜或下一模型的稳定构图和状态。

运镜只能由人物移动、注意力转移、空间揭示或关系变化触发。无触发则固定或仅作维持构图所需的微调。禁止无因环绕、习惯性推进/拉远、为每句对白换景别、用镜头术语替代人物动作。越轴、屏幕方向翻转或视线关系改变必须有可见空间重建或剧情理由。

每次切镜先写理由，再选景别和机位。一个机位已经能承载完整表演或动作时不切；新镜头必须带来新的空间、信息、关系、动作读法或主观感知。

最终提示词不先报镜头清单。环境、人物和动作构成句子主干，摄影只作为观看动作融入因果：“人物靠近窗边，画面跟着他的肩线越过桌角”“门打开后，走廊冷光把两人从暗处勾出，原本停在手上的注意力回到他们的脸”。若删掉摄影术语，人物在做什么、为何改变观看位置仍应清楚。

## 2. 全局光影圣经

`visual_bible.lighting` 锁定连续空间的共同基线：时间/天气、有来源的主光、主光方向与光质、明暗反差、补光策略、人物与背景分离、综合色温关系、曝光重点、实景灯及材质反应。它描述可观察结果，不伪造灯具功率、照度、色温数值或镜头参数。

ARRI 的基础实践可归纳为：先确定有动机的主光，再判断是否需要补光控制反差，以背景/轮廓或实景灯完成空间分离；灯光方向和强度应让场景来源可信。参考：[ARRI Lighting Handbook](https://www.arri.com/en/learn-help/lighting/lighting-handbook)。

## 3. 片段光影状态

每段 `lighting_state.start/end` 至少记录有动机光源、主光方向、综合色温关系和曝光重点。起止状态不同，`change_trigger` 必须绑定时间、地点、灯源或剧情事件，例如人物关灯、门被打开、车辆驶过或天色真实变化。

同一连续空间不得无因翻转主光方向、冷暖关系或曝光重点；跨镜先继承，再描述变化。服装、皮肤、金属、玻璃、潮湿表面等材质反应只写与当前观看目标有关的部分。

## 4. 桥接摄影

跨段优先保持轴线、屏幕方向、焦点落点、主光方向和结束构图。动作匹配只有在前后动作具有相同向量或形状且能推进叙事时使用；J/L 声音桥只有在声音来源和时序成立时使用。参考：[Adobe Match Cut Guide](https://www.adobe.com/creativecloud/video/post-production/cuts-in-film/match-cut.html)。

跨 Seedance/Wan 时优先设计中性的共享边界关键帧：它停在合法、非明确且两边都能使用的稳定状态，不把成人行为偷偷放入正常路。若不能共享图片，则将完整人物位置、覆盖、支撑、呼吸、光向、声音尾部与下一动作入口写入 `transition_ledger`。

## 5. 编译检查

- 运镜是否能指出唯一触发事件；
- 焦点变化是否与注意力变化一致；
- 切镜是否带来新的观看价值；
- 光源是否在场景中有来源，变化是否有 `change_trigger`；
- 结束构图能否无跳变地交给下一段；
- 删除摄影术语后，提示词是否仍清楚说明为什么这样看。
