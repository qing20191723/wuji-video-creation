# 成人亲密动作编排

仅在 `adult-intimacy.md` 已确认所有参与者成年、来源获授权、持续自愿，且内容等级、镜头与覆盖边界已批准后读取。本文件组织已批准成人动作，不扩大尺度；具体解剖与行为用词由 `adult-explicit-language.md` 提供。

## 1. 动作节拍语法

每个 `intimacy_beat` 按真实时序记录：

`发起 → 明确回应 → 动作族 → 接触图 → 支撑与重心 → 运动方向和节奏 → 服装/覆盖变化 → 同步声音 → 暂停/停止/接续 → 末状态`

这是一套内部编排契约，不是最终提示词字段。编译到 Wan 3.0 时，将相邻节拍改写为连续自然的导演叙述；禁止把字段名、代码枚举或动作词库打印给模型。

在已批准尺度和当前执行环境允许范围内，编排应达到最大可执行直述精度：直接写裸体/覆盖程度、姿态几何、承重、已批准行为类别、动作方向与节奏变化、主动回应、暂停和末状态，不用“更加亲密”“继续动作”代替可见事实。不能展开的细部机制仍要以中性行为类别和唯一原文跨度保留，不能消失。

## 2. 动作族

动作族只用于追踪原文和判断拆段点：

- `approach_confirmation`：接近与确认；
- `kissing_caressing`：接吻与爱抚；
- `coverage_change`：服装或覆盖变化；
- `manual_or_oral`：已批准的手部或口部行为；
- `self_stimulation`：已批准的自我刺激；
- `intercourse`：已批准的性交行为；
- `position_support_transition`：姿态、承重或支撑转换；
- `pause_stop_reconfirm`：暂停、停止或重新确认；
- `completion_aftercare`：结束与事后照料。

不得建立姿势百科，不从动作族自动推导具体姿态、身体部位、强度或结果。原文只到接吻，就不能因为后续动作族“可用”而升级为性行为。

## 3. 完整性与连续性

每个节拍必须回溯到一个属于该成人片段的 `source_span_id`，时间连续、无重叠、无空缺，末点等于实际片段时长。每个节拍必须写清：

- 谁发起，另一方如何主动、明确且可撤回地回应；自我行为标记 `self_directed`；
- 身体或物件接触的双方落点，什么支撑谁、重心如何转移；
- 运动向量和节奏如何由上一动作结果产生；
- 覆盖前后状态、镜头可见范围和遮挡边界；
- 呼吸、克制的非语言发声、身体接触、衣料、床品、家具/支撑面和环境声的画面来源、强度弧线与远近变化；
- 暂停、接续或停止后的稳定末状态。

同意不是段首一次性标签。涉及动作族、接触范围、覆盖、姿态支撑或强度改变时，都要有可见/可听的 `consent_checkpoint`。任何迟疑、停止信号或撤回应立即进入 `pause_stop_reconfirm` 或结束，不用镜头语言掩盖。

声音随真实动作和空间变化，不设置叫声数量或固定拟声配额。可听见的内容必须能指向人物呼吸/非语言回应、皮肤或衣料接触、床品/家具承重、房间底噪等明确来源；不凭空加入明确台词或重复声音填满 30 秒。

该记录方式依据行业对具体行为、呈现范围、描述语言和持续同意的要求整理：[SAG-AFTRA Intimacy Protocols](https://www.sagaftra.org/standards-and-protocols-use-intimacy-coordinators-0)。本 Skill 台账不替代真实片场协调、合同或安全流程。

## 4. 拆段与镜头

先按完整动作因果试演，再决定时长。超过当前 Wan 上限时，只在动作族、支撑体系、同意检查点、台词停顿或结果变化处拆分；短于 30 秒的末段保留实际时长。禁止用重复动作、提高频率、空镜、无因声音或频繁跳镜头凑满容器。

同一支撑体系和观看理由下优先连续镜头。切镜只在新的空间、关系、动作读法或安全呈现边界出现时发生，并继承手部落点、重心、覆盖、呼吸和声音尾部。

## 5. 输出检查

- 每个节拍是否有唯一原文跨度，且剧本尺度没有被升级；
- 发起、回应、接触、支撑、覆盖、声音、检查点与末状态是否齐全；
- 节拍是否覆盖真实时长且没有注水；
- 镜头是否遵守已批准可见范围和遮挡边界；
- 最终 Wan 提示词是否为连续自然导演稿，而非字段清单。
