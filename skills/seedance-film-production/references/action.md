# 自适应武戏导演系统

## 1. 结构与目标

- 先完成一个可读的战术单元，再按动作、喘息和反馈估算时长；不得超过当前模型入口上限；
- 使用最少充分镜头，不设固定宏观镜头数；
- 先明确双方目标、战术差异、空间轴线、武器属性、胜负条件和环境利用点；
- 战斗必须讲清策略变化，禁止无目的互打；
- 每个主要攻击都有起势、加速、接触、受力反馈、余势；
- 防守方必须格挡、闪避、卸力或反制，不能是木桩；
- 人物的战术目标与故事状态沿 A→B→C→D 前进，末镜不复刻首帧原点；这不限制物理路线折返、绕行或屏幕方向反转，但这些变化必须在空间和轴线上重新交代。

## 2. 战术单元与时间

每段先确定：初始距离与轴线、双方当下目标、第一种策略、策略失效的证据、调整方式、胜负或暂时结果。只有真实发生的环节才写，不强行补齐完整升级曲线。

逐拍试演动作和受力反馈，得到目标时长。镜头时间必须连续、无空缺和重叠，末点等于该段实际 `duration_seconds`。短战术交换可以很短；内容超过平台上限时在换策略、换空间或胜负阶段处拆段。

## 3. 镜头与动作节点

- 故事板格数服从已批准镜头，不反过来决定叙事结构；
- 动作节点是镜内的攻、挡、闪、反制、接触、反馈和余势；
- 日式 Sakuga 路线可使用高密度动作节点和镜内微切，但密度来自当前动作设计，不设数量指标；
- 写实路线以清晰、重量和因果优先，一个镜头能完整读清攻防时不拆；
- 国风/AAA CG路线平衡可读动作、能量轨迹和大尺度反馈；
- 微切落在动作中段，方向匹配，不能产生发飘、变形或无因跳位。

## 4. 故事板构图选择

- 环境主导、单人动作、POV、身体局部、武器特写和双人同框按可读性选择，不设格数配额；
- 只有空间不清、接触点读不清或双方动作关系变化时才换构图；
- 正常完整生产的 4×4 是视觉锁定交付，不是 16 个视频镜头的配额。实际镜头少于 16 时，一镜可用多个有因果价值的动作相位；有效状态不足时让画板覆盖相邻且相关的正常叙事段落。仍不足且继续补格只会注水时，写明理由并把 G6 标为 `not_required`，改用已批准关键帧/分镜资产，不能填无信息动作。

相邻镜头至少改变景别、机位高度、镜头方向、人物显隐、速度、空间层级或叙事信息之一。禁止连续三镜相似双人中景对打。

## 5. 首帧、武器与敌人

- 镜头1忠于参考图已有主体、姿势和景别，先让主体自然动起来；
- 区分明确武器、临时工具和生活道具；茶杯、酒杯、餐具、书卷、普通首饰不自动成为武器；
- 无明确武器时默认空手，动作从体型、重心、关节链、步法和格斗流派生长；
- 首帧生活道具在镜头1通过放下、抛出、脱手或打碎因果退场，交代方向和落点；
- 新敌人从镜头2后通过门窗、高处、远景、阴影、载具或逐步打开的裂口入场；先见环境反应，再见完整敌人。

可使用E1试探单位→E2精英→E3首领：同势力血缘，但轮廓、主色、武器和能力清晰区分。E2至少挡招和反制各一次；E3压制常规招、改变战场并逼出核心机制。

## 6. 场景破坏阶梯

- S1局部物件；
- S2房间/结构；
- S3建筑群/地形；
- S4地标/天象。

前级痕迹在后续持续可见，新破坏从旧痕迹向外扩展。不从S1直接跳S4，不在大招后恢复小尺度无损场景。

## 7. 动作—反馈闭环

关键攻击按：

1. 起势装弹：沉肩、下沉、压步、武器后拉、短吸气；
2. 加速：发力顺序、方向、速度、轨迹；
3. 接触：具体命中/格挡/擦过位置；
4. 重音：短震镜、白闪、径向模糊或音效，画面不停；
5. 受力：沿力线压缩、旋转、滑退、击飞或卸力；
6. 反馈：护甲凹陷、火花、裂纹、碎石、水花、尘环、能量波纹；
7. 余势：完整收势，武器、衣摆、发丝和碎屑持续运动；
8. 接续：上一招收势成为下一招起势。

使用旋斩、挑刺、格挡反刺、横扫、崩拳、膝顶、瞬身、蹬墙、侧翻卸力、借力回旋、能量迸发等具体动词。招式必须从当前角色的身体、武器、战斗部件和世界观现场设计，不套固定成品招。

## 8. 速度、切镜和空间

每个回合采用：

`低幅度蓄势 → 高速攻防 → 命中重音 → 受力反馈 → 短促换气`

- 慢拍保持微运动，不是整帧冻结；
- 命中短暂速度渐变时，碎屑、火花、水花和发丝仍在流动；
- 随后迅速恢复全速；
- 每次爆发前给独立可读的蓄势；
- 全片最多一次明显名场面升格；
- 禁止长时间定格、时间静止和无流动元素的子弹时间；
- 硬切落在挥砍、突进、翻身或受力中段，保持方向和动势；
- 完整挥出并保留follow-through；
- 怼脸冲击改变侧、仰或斜角，不重复首帧正面。

## 9. 视觉路线

- 电影写实：真实重量、克制震镜、清楚空间、材质反馈、有限VFX。
- 国风/奇幻/AAA CG：写实材质上增加能量轨迹、体积光、法术几何和大尺度环境反馈。
- 日式番剧/Sakuga：速度线、集中线、残影、smear、极短黑白闪/单色染屏、抽象线条背景和高密度微切。

参考图优先；无证据默认电影写实。黑白闪或染屏必须极短、与动作同步、闪完即回。

## 10. 动作类型路由

先判断主类型，只加载当前段需要的动作语法；混合段最多组合两类：

| 类型 | 关键约束 |
|---|---|
| 自由格斗 | 拳脚、肘膝、摔投、擒拿或缴械必须写起手、接触部位、受力方向和地面/站立关系 |
| 武侠兵器 | 写清兵器轨迹、交击部位、借力点、轻功起落点；兵器尺寸、软硬属性和持手不漂移 |
| 异能战斗 | 写清能力来源、视觉形态、作用对象、物理结果和角色代价，禁止无来源光污染 |
| 战场群战 | 先分前景主行动、中景压力、远景战线；写清敌我方向、阵线变化和群体声音层 |

追逐不需要伪装成新的战斗类型，但必须单独写追逐台账：`追方/逃方 → 空间目标 → 路线与转角 → 障碍 → 相对距离变化 → 双方屏幕方向 → 速度变化触发 → 段末位置与未完成意图`。转角、遮挡或跨空间时重新交代轴线和地标；不能只写“开始追逐”。混合类型先服从决定胜负的主机制，再补一个真正影响动作物理或场面调度的次类型。

## 11. 类型化动作语法

- 自由格斗：`距离变化 → 进攻起手 → 防守/闪避 → 接触或落空 → 反击 → 拉开/压制状态`。
- 武侠兵器：`身法路径 → 兵器轨迹 → 交击/借力点 → 双方受力 → 兵器与站位落点`。
- 异能战斗：`来源 → 成形 → 作用对象 → 环境与身体结果 → 反噬/消耗 → 段末范围`。
- 战场群战：`战场层次 → 主行动线 → 群体压力 → 关键接触 → 战线结果 → 段末阵型`。

不要把类型库当招式清单。具体动作必须从人物体型、训练、兵器、能力、地形和当前目标生长；不为提高密度让所有攻击命中，也不在镜内省略反馈和喘息。
