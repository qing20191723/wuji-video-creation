# V5 采光院拼接与复核说明

状态：2026-10-15 的待审模型提案；正式场景出图暂停。尺寸均为影视设计参考，不是实测建筑尺寸。

## 本轮采用的用户决定

以指定「场景图V3版」为主参考。已盘点 81 张图片并查看 26 页联系表，清单和 SHA-256 在 `V3参考索引.json`。用户明确选择「优先保留 V3 卧室，允许走廊局部转折或增加采光院」。原素材不删除。

这意味着原来同一面墙上的直线三门不再是硬条件。主路线依次连接薇亚、子豪、舒亚；新关系需要通过平面图和转折机位交代，不能再让普通相机强行三门同框。

## 返工原因与本次改变

1. 旧模型把三间卧室统一套进 7.4×3.8m 的条形房间，再让 AI 恢复装修。家具、双窗、阳台墙关系已经改变，材质提示词无法挽回结构差异。
2. 只验证对象没移动、路线能走通，并不等于房间像原图。本次先建独立房间，逐项对应床、窗、书桌、柜体、梳妆与运动区，再平移或旋转拼入全屋。
3. 旧预览截矮墙造成门墙与护栏一样高。当前模型墙高 3.08m，去顶检查只隐藏顶板；SVG 另行标注剖面高度，不能当正式摄影。
4. 厨房、餐厅、客厅的邻接不能由简单房间框推导。本次恢复客厅与餐厅隔电视墙并排、厨房在餐厅后方的 L 形关系；取消旧餐厨前厅。
5. 生成图、结构图、待审图混放会放大错误。本轮交付仅为中性模型、技术图和对照，不制作新的正式场景图。

## 全屋新增设计与外立面影响

- A 端在前侧二楼上平台；沿 A→B 下至后侧一楼。20 踢面、19 踏面、层高 3.3m，楼梯包含斜板、上下连接和实体侧支承，不是漂浮踏步。
- 大姐位于前部，窗朝采光院，阳台门位于相邻侧墙。子豪位于院后，舒亚位于后侧翼。走廊在楼梯后转向，再转入侧翼。
- 一楼公共交通分别接主卧套房与家政服务区；洗衣房与客卫有自己的真实体量。二楼补公用浴室、浅布草柜和后露台。
- 新增临街入口玻璃廊、庭院、后部套房体量、露台和可见柱支承。因此 HOME 的实际外形与原外景紧凑长方体不同；SITE 是早期体量对照，不能当新方案的外观。外立面需一并审看。
- 每空间固定 Logo 载体已记录，但当前是中性几何牌，未宣称品牌字形、金白材质或姓名牌已完成正式呈现。

- 1974 个对象、32 个检查机位；656 个全屋房间复制对象尺寸保持一致；30 项局部间隙无失败。
- 子豪房门→A→下楼→B→客餐厨路径，538 个采样无列检实体碰撞。楼梯之外，以 5cm 网格、直径 0.52m / 高 1.75m 人体近似，验证 16 个房间/平台目标点均可达且有楼板支撑。

- 离线 HTML 8 个模块加载成功，无外网请求及浏览器脚本异常。实际查看全屋平面、外部体量、楼梯与主要房间预览；中性模型不能代替原图材质验收。
- 下次先复核：卧室家具/窗门方向、采光院位置、转折路线、整体外形与室外距离。通过后再精细化门扇开启与家具网格、材质和灯光，最后恢复场景图片制作。
