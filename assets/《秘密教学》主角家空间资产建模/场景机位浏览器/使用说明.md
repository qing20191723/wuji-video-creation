# 秘密教学 · 镜头工作台

双击 `打开机位浏览器.cmd`，使用当前电脑的浏览器选角度。工作台只读取相邻目录中的 P4-M2 GLB 实体，不加载历史模型；Three.js r180 及加载组件已随包提供，运行时不访问外部CDN。需要本机Python 3.10或更新版本；启动脚本优先使用已有Codex Python。

1. 选择空间及预设机位，共176个。默认9:16，可切16:9或1:1。
   四间卧室（含一楼主卧）、客厅、餐厅各25个；可按“四角斜看／对向全景／家具与品牌／高低机位／原有机位”筛选。其余空间保留现有26个。机位覆盖主要方向，任意中间角度可自由调整并保存。
2. 拖动环绕、右键平移、滚轮调远近，也可调整视野、相机高度、前后左右微移和原地转头。
3. 点击“保存机位与预览”，写入本目录 `我的镜头/`。加载已保存镜头后再保存，更新同一个编号；选择其他预设再保存会创建新镜头。
4. 点击“选此机位生图”，保存相机、PNG预览和待生图标记。回到对话发送“按已选机位生图”，或复制页面给出的具体镜头编号。网页不会自动调用AI，也不会自动给对话发送消息。

每条记录含P4-M2实体模型SHA-256、坐标、目标点、Z向上方向、垂直视角、画幅及备注。预览固定导出720×1280、1280×720或1080×1080，无界面按钮和辅助线。水平翻转仅用于检查品牌，不改变实际相机和导出方向。剖切总览用于找位置，切回完整场景才允许保存或提交生图。

这是基础材质的实时取景参考，不是最终写实图；当前模型没有精细织物或完整写实灯光。后续生成仍需逐张核对空间、门窗、家具、品牌与文字，不把AI图片视为精确三维投影。

## 接手生图

读取 `我的镜头/待生图清单.json`，再读取对应的 `shot-….json` 和PNG。仅处理用户当次要求的镜头；保留门牌正常方向、品牌整组镜像以及 `hgdju.com`。模型指纹不一致时先核对版本，不沿用失效坐标。数据、截图与用户确认共同作为依据。

相机坐标为Blender世界坐标：X向东、Y向北、Z向上，单位米。浏览器将GLB的Y向上坐标转换回该坐标系。垂直视角与画幅同时保存，不能仅按一个焦距猜测构图。

## 验证

`check_browser.cjs` 使用本机Playwright和Chrome检查机位、保存恢复、同编号覆盖、画幅、翻转、剖切限制与界面。测试必须使用 `server.py --no-browser --data-dir <独立临时目录>`，不能向用户“我的镜头”写测试数据。`STUDIO_TEST_URL` 指定测试服务；`STUDIO_CHECK_DIR` 指定检查结果目录。

`check_coverage.cjs` 检查125个新增机位在9:16和16:9画幅下的近距遮挡，输出六个空间的构图检查页，并验证方向分类筛选。结果见 `机位覆盖检查.json`；基础材质预览仅用于选机位。
