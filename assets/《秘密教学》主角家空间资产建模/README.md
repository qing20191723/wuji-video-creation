## 当前数据与制作边界

`模型/空间主数据_v4.json` 是唯一空间数据；三个保留模型文件未改坐标，校验值见 `制作记录/当前保留文件校验.json`。二维图、浏览器和 Blender 应使用同一数据，不再分别改布局。

恢复连接关系不等于原房间材质、家具和外立面已经复刻。先检查平面关系，再逐项细化；不能因为原图局部矛盾就再次拆开三个卧室。保留模型和已批准 V3 参考之间仍有待校准的房间比例与窗门差异。

## 复现

在本目录执行；Python 需 NumPy，浏览器检查需 Playwright、Sharp 与 Chrome，可配置 `NODE_PATH` / `CHROME_PATH`。

```powershell
git lfs pull
python scripts/check_and_draw.py
python scripts/package_review.py
node scripts/check_current.cjs
blender -b --disable-autoexec --python scripts/verify_blend.py
```

需要改结构时才编辑 `build_scene.py` 并重新构建；日常查看不要重新建模。`build_blender.py` 与 `build_scene.py` 是保留的 V4 构建工具。默认不生成新的正式场景图。
