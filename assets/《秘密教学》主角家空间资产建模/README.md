## 复现与检查

Python需NumPy；PNG导出需Node.js、Playwright和Chrome，可配置 `NODE_PATH` / `CHROME_PATH`。

```powershell
python scripts/draw_plan_review.py
python scripts/check_plan_review.py
node scripts/render_plan_review.cjs
```

几何检查覆盖家具、12处使用区、9扇门的采样扫掠、18处功能区可达性和3条路线。采用0.50m直径人物足迹，不构成三维净高、结构承重或施工合规验收。PNG长边3600像素，SVG保留可编辑文字和图元。

`build_scene.py`、`build_blender.py`、`check_and_draw.py` 为既有V4复现工具，本轮不要运行以免重建旧布局/旧图纸。

专用私有分支：`codex/20261014-secret-teaching-home-assets`。模型后续修改以本轮平面确认结果为条件。
