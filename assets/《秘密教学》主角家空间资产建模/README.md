## 数据边界

`平面确认/平面方案数据.json` 是待确认二维提案；`scripts/draw_plan_review.py` 调用 `plan_p2.py` 与 `plan_svg.py` 统一生成图纸，不修改 `模型/`。全部图纸同向同坐标，场地拟定30×25m。尺寸、门距和室外配置为设计推导，不是实测。主卧整套参考关系逆时针旋转90°接入东侧，其他卧室不镜像。

既有模型仅保留一套：[V4查看入口](打开检查模型.html) · [Blender](模型/秘密教学_全屋空间_v4.blend) · [GLB](模型/秘密教学_全屋空间_v4.glb)。页面已标明尚未更新。三份模型文件与原 SHA-256 一致，见 `平面确认/平面几何检查.json`。

本轮七张平面图和一页修改说明确认后，再更新唯一模型。旧平面交付已从日常目录撤下，历史通过 Git 追溯；原始参考保留。不得以待确认提案自动恢复场景生成。

## 复现与检查

Python需NumPy；PNG导出需Node.js、Playwright和Chrome，可配置 `NODE_PATH` / `CHROME_PATH`。

```powershell
python scripts/draw_plan_review.py
python scripts/check_plan_review.py
node scripts/render_plan_review.cjs
```

几何检查覆盖家具、12扇门的采样扫掠、22处功能区、14处实际使用位置及4条指定路线。采用0.50m直径人物足迹，不构成三维净高、结构承重或施工合规验收。PNG长边3600像素，SVG保留可编辑文字和图元。

`build_scene.py`、`build_blender.py`、`check_and_draw.py` 为既有V4复现工具，本轮不要运行以免重建旧布局/旧图纸。
