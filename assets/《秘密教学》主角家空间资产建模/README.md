## 数据边界

`平面确认/平面方案数据.json`为统一空间数据，墙体、门窗、家具、楼板分块和挑空共同驱动图纸与白模。主体22×10.4m、地块26×23.7m及4.5m前庭为影视设计暂定尺度，由用户校准。

R2撤除走廊侧高墙，14.92m连续挑空中保留原5.32m梯段。公卫、布草后移占用部分原东南露台。新增挑空下方为一楼公共区，支承、管线、隔声与外立面仍待复核。不能宣称已完全还原参考或完成全屋空间验收。

## 复现

`python scripts/plan_p2.py`生成平面数据及SVG；`node scripts/render_plan_review.cjs`导出PNG；Blender运行`scripts/build_p23.py -- --render --cameras H2_REFERENCE,H2_END_W,H2_END_E,H2_MID_W,H2_VOID_CHECK,H2_PLAN,STAIR_UP,STAIR_DOWN`生成本轮局部图。完整覆盖前不批量生成装修图。

专用私有分支：`codex/20261014-secret-teaching-home-assets`。当前模型、源数据、参考与清单已备份，LFS远端回读通过。大量PNG留本地，仓库记录校验值。仅清理了本轮已失效候选图和检查记录；全项目其余旧成果需在完整替代交付验证后继续回收。
